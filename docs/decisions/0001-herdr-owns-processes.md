# 0001. Процессами агентов владеет herdr

В условиях, когда агенты Claude Code уже работают в панелях herdr и
herdr предоставляет API сокета (снимок, события, чтение панелей, запуск
и приглашение агентов), учитывая, что порядок работы с агентами должен
остаться прежним, выбрано сделать плагин клиентом сокета API herdr, а
процессами агентов оставить во владении работающего сервера herdr, чтобы
Neovim показывал и направлял те же сессии, что видны в herdr, и не
воспроизводил интерфейс Claude Code, ценой зависимости от API форка herdr
и невозможности структурированно писать субагентам.

## Отвергнутый вариант

Запуск `claude -p --input-format stream-json --output-format stream-json`
дочерними процессами Neovim. Он заменял бы herdr для этих сессий и требовал
бы воспроизводить интерфейс Claude Code: разрешения, вопросы, статусы и
приглашение.

## Следствия

- Агентам пишут через `agent.prompt`, `pane.send_text` и `pane.send_keys`;
  субагентам писать нельзя: у них нет панели.
- Состояние субагентов и фоновых команд плагин читает из файлов Claude Code
  ([`../data-sources.md`](../data-sources.md)).

## Условия пересмотра

Появление в Claude Code документированного канала управления сессией и его
перечня субагентов и фоновых задач.
