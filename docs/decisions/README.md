# Записи решений

Запись фиксирует выбор между вариантами: инструмент, процесс, размещение
компонента. Поведение, которое проверяется сценарием, описывают спецификации
OpenSpec, а не записи.

## Форма

Запись — Y-statement: «в условиях …, учитывая …, выбрано …, чтобы …, ценой …».
Под ним — отвергнутые варианты и условия пересмотра.

## Правила

- Файл называется `NNNN-тема.md` (латиницей, слова через дефис), номер порядковый.
- Запись правится на месте, когда решение изменилось; неактуальная запись
  удаляется, новое решение получает новую запись.
- Текст — только принятые решения, без хронологии и обсуждений.
