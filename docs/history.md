# История сессий

История показывает прошлые сессии Claude Code того проекта, в котором работает выбранная
панель, и открывает их диалог для чтения. Перечень строится по файлам Claude Code на диске;
сервер herdr нужен только для отметки сессий, которые сейчас работают.

## Вызов

В дереве ([дерево](tree.md)) поставьте курсор на панель с агентом Claude Code и нажмите `H`.
Для субагента и фоновой команды берётся панель-владелец. На других узлах плагин сообщает, что
нужна панель с агентом.

Подкоманда:

```vim
:Claudr history [панель или сессия]
```

- Без аргумента: если курсор стоит в окне дерева, берётся узел под курсором, иначе плагин
  предлагает выбрать одну из панелей с Claude Code из снимка herdr. Без подключения к herdr
  панелей нет — откройте дерево (`:Claudr tree`) или укажите сессию.
- С идентификатором панели (например, `w1:p1`) берётся сессия этой панели.
- С идентификатором сессии Claude Code перечень строится без сервера herdr.

## Перечень сессий

Каталог проекта определяется по расположению транскрипта сессии выбранной панели. Если
транскрипта ещё нет (сессия только запущена и ничего не записала), плагин сообщает, что
каталог проекта неизвестен, и перечня не показывает.

Перечень открывается через `vim.ui.select` (его заменяют установленные у вас плагины выбора).
Строка содержит:

- отметку `●` у сессии, которой соответствует живая панель herdr (по `agent_session` панели);
- идентификатор сессии;
- время последней записи в транскрипт;
- начало первой реплики пользователя (длинная реплика обрезается).

Новые сессии идут первыми. Без сервера herdr перечень работает так же, но отметок `●` нет.

Темы [вопросов по коду](code-questions.md) в перечень не входят: они показываются только в
перечне тем (`:Claudr topics`).

## Просмотр диалога

Выбор строки открывает диалог в новом окне справа: реплики пользователя (`Пользователь:`) и
агента (`Агент:`) в порядке записи. Буфер только для чтения; `q` закрывает окно. Если
транскрипт исчез между показом перечня и выбором, плагин сообщает, что транскрипт недоступен.

## Срок хранения

Срок хранения транскриптов задаёт сам Claude Code (по умолчанию 30 дней, настройка
`cleanupPeriodDays`). Плагин срок не меняет и копий транскриптов не хранит: удалённая
Claude Code сессия из перечня пропадает.
