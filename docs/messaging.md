# Сообщения и запуск сессий

Из Neovim можно написать агенту, отправить ему клавиши и запустить ещё одну сессию Claude
Code. Все действия идут через сервер herdr; без сервера они завершаются сообщением о
недоступности сервера, ничего не откладывается и не создаётся.

## Куда направлено действие

Цель действия — узел дерева ([дерево](tree.md)):

- в окне дерева действие применяется к узлу под курсором (клавиши ниже);
- подкоманда из командной строки берёт узел дерева под курсором, если окно дерева открыто на
  текущей вкладке; идентификатор панели можно указать аргументом (`:Claudr message w1:p2`);
- если узла нет, плагин предлагает выбрать цель из перечня (`vim.ui.select`).

## Сообщение агенту

| Способ | Действие |
|---|---|
| `m` в окне дерева | сообщение агенту выбранной панели |
| `:Claudr message [панель]` | то же из командной строки |

Плагин запрашивает текст (`vim.ui.input`) и отправляет его агенту выбранной панели. Если
выбран workspace или вкладка, предлагается перечень панелей с агентом внутри них. Пустой
текст и отмена ввода ничего не отправляют.

### Агент ждёт ответа

Агент в состоянии `blocked` (диалог выбора, запрос разрешения) не принимает сообщений:
сервер отклоняет отправку, текст не попадает в панель. Плагин показывает, что агент ждёт
ответа, и предлагает отправить клавиши (пункт «Отправить клавиши»). Текст сообщения другим
способом не отправляется: сначала ответьте на диалог клавишами, затем повторите сообщение.

## Клавиши агенту

| Способ | Действие |
|---|---|
| `K` в окне дерева | отправить последовательность клавиш в выбранную панель |
| `:Claudr keys [панель]` | то же из командной строки |

Плагин запрашивает клавиши одной строкой: имена через пробел или запятую, например
`down down enter` или `enter`. Клавиши уходят в панель одной последовательностью, в том
числе когда агент в состоянии `blocked`. Когда диалог закрыт, состояние агента в дереве
становится `idle`.

## Субагентам и фоновым командам писать нельзя

У субагента и фоновой команды нет панели, поэтому сообщения и клавиши для них отклоняются:
«у узла нет панели». Запросов к серверу при этом не делается. Писать можно только агенту
панели, в которой запущен субагент или команда.

## Запуск сессии Claude Code

| Способ | Действие |
|---|---|
| `L` в окне дерева | запустить сессию, цель — узел под курсором |
| `:Claudr launch` | запуск, цель — узел под курсором дерева или выбор из перечня |
| `:Claudr launch tab` | сессия в новой вкладке |
| `:Claudr launch split [right\|down]` | сессия делением панели |

Способы запуска:

- **Новая вкладка.** В выбранном workspace создаётся вкладка, в её корневой панели
  запускается агент `claude`. Цель — workspace, либо вкладка или панель (берётся их
  workspace). Без выбранного узла плагин предлагает перечень workspace.
- **Деление панели.** Выбранная панель делится, в новой панели запускается агент. Цель —
  панель; для вкладки или workspace плагин предлагает перечень их панелей. Направление
  выбирается из двух: вправо или вниз.

Для узла вкладки или панели без указанного способа плагин спрашивает, как запускать; для
workspace и без узла — открывается новая вкладка.

Рабочий каталог плагин не передаёт: действует каталог по умолчанию herdr. Запуск идёт
асинхронно, Neovim остаётся отзывчивым. Плагин не ждёт, пока агент будет готов: как только
сервер принял запуск, появляется сообщение «агент Claude Code запускается», а когда агент
встанет у приглашения (состояние `idle`), — сообщение «агент готов». Если панель закрыли
раньше, плагин сообщает, что панель закрыта. Новая сессия появляется в дереве сама, по
событиям herdr. Идентификатор сессии известен сразу после запуска, а файл диалога
появляется только после первого сообщения в сессии: до него у панели нет истории, и это не
ошибка.

### Ошибки запуска

Если создание вкладки, деление или запуск агента завершились ошибкой, плагин показывает код
и текст ошибки сервера. Уже созданные вкладка или панель остаются на месте, плагин их не
закрывает и запуск не повторяет.

### Диалог доверия к каталогу

Если Claude Code ещё не доверяет рабочему каталогу, агент останавливается на диалоге
доверия (состояние `blocked`). Вместо сообщения о готовности плагин сообщает, что агент не
готов и ждёт ответа на диалог. Созданная панель остаётся, повторного запуска плагин не
делает. Ответьте на диалог, подключившись к панели с вводом (клавиша `i` дерева или
`:Claudr attach [панель]`, см. [подключение к узлам](node-view.md)), либо отправьте клавиши
(`K` или `:Claudr keys [панель]`, например `down enter`).
Когда диалог закрыт, узел панели показывает состояние агента по событию herdr: `idle`.

## Клавиши дерева и подкоманды

| Клавиша в дереве | Действие |
|---|---|
| `m` | сообщение агенту |
| `K` | клавиши агенту |
| `L` | запуск сессии |

| Подкоманда | Действие |
|---|---|
| `:Claudr message [панель]` | сообщение агенту |
| `:Claudr keys [панель]` | клавиши агенту |
| `:Claudr launch [tab\|split [right\|down]]` | запуск сессии |
