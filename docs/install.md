# Установка и настройка

## Зависимости

- Neovim 0.12 и новее. Сторонние плагины Neovim не нужны.
- Работающий сервер herdr с API сокета (протокол 22 и новее). Плагин подключается к нему
  сам, сервер не запускает.
- Claude Code (команда `claude` в `PATH`). Каталог данных Claude Code плагин ищет в
  `$CLAUDE_CONFIG_DIR`, а без этой переменной — в `~/.claude`.

## Установка

Без менеджера пакетов: клонировать репозиторий в каталог пакетов Neovim.

```sh
git clone <адрес репозитория> ~/.local/share/nvim/site/pack/claudr/start/claudr.nvim
```

Со встроенным менеджером `vim.pack`:

```lua
vim.pack.add({ "<адрес репозитория>" })
require("claudr").setup()
```

С менеджером пакетов (пример для lazy.nvim):

```lua
{
  "<адрес репозитория>",
  opts = {},
}
```

После загрузки плагина доступна команда `:Claudr`. Подкоманды появляются после вызова
`require("claudr").setup()`; сам по себе плагин при загрузке ничего не запускает и к herdr
не подключается.

## Настройка

```lua
require("claudr").setup({
  show_finished = true,
  code_questions = {
    model = "sonnet",
    fork_from_base = false,
  },
})
```

| Настройка | По умолчанию | Назначение |
|---|---|---|
| `show_finished` | `true` | Показывать в дереве завершённые субагенты и фоновые команды. Переключается командой дерева (см. [дерево](tree.md)). |
| `code_questions.model` | `"sonnet"` | Модель, которая отвечает на вопросы по коду. |
| `code_questions.fork_from_base` | `false` | Ответвлять новую тему вопросов от базовой сессии проекта. |
| `code_questions.base_session` | не задана | Базовая сессия проекта для `fork_from_base`. |
| `code_questions.mcp` | не задана | Необязательный MCP-сервер проекта как источник знаний для вопросов по коду. Без него плагин работает. |

Значения настроек `code_questions` подробно — в разделе «Настройки» [вопросов по коду](code-questions.md).

Пропущенные настройки берут значения по умолчанию.

## Команды

Все команды плагина вызываются как `:Claudr <подкоманда> [аргументы]`; имена подкоманд
дополняются по `<Tab>`. Перечень подкоманд — в руководстве по соответствующей возможности
(см. [указатель](README.md)).
