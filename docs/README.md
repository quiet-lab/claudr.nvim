# Руководство пользователя claudr.nvim

- [Установка и настройка](install.md) — зависимости, подключение плагина, вызов `setup`,
  перечень настроек.
- [Дерево](tree.md) — дерево workspace, вкладок, панелей, субагентов и фоновых команд.
- [Подключение к узлам](node-view.md) — наблюдение за выводом узла, подключение с вводом,
  история панели.
- [Сообщения и запуск сессий](messaging.md) — сообщение агенту, клавиши агенту, запуск
  сессии Claude Code.
- [Окно ввода сообщения](message-input.md) — набор сообщения агенту, отправка, черновик,
  защита текста с `/` и `!`.
- [История сессий](history.md) — перечень прошлых сессий проекта и просмотр диалога.
- [Ссылки на файлы](file-references.md) — предпросмотр и открытие файла по пути под курсором
  в буферах плагина.
- [Вопросы по коду](code-questions.md) — темы вопросов, контекст из буфера, настройки.

|---|---|

| `message`, `keys` | [Сообщения и запуск сессий](messaging.md#клавиши-дерева-и-подкоманды) |

| `history` | [История сессий](history.md#вызов) |
| `ask`, `ask-selection`, `ask-file`, `topics`, `topic-last` | [Вопросы по коду](code-questions.md#команды) |

| `<CR>`, `i`, `S` | [Подключение к узлам](node-view.md#клавиши) |

[подключении к узлам](node-view.md#клавиши) и [вопросах по коду](code-questions.md#клавиши).
