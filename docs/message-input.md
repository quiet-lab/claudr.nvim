# Окно ввода сообщения

Сообщение агенту набирается в плавающем окне с обычным буфером Neovim: все привычные
команды редактирования, многострочный текст, вставка, регистры. Это же окно используется и
для других текстов, которые плагин отправляет агенту (например, свободного ответа на
вопрос в [буфере диалога](agent-dialogs.md)).

## Как открыть

| Способ | Действие |
|---|---|
| `m` в окне дерева | окно ввода для выбранной панели с агентом |
| `:Claudr message [панель]` | то же из командной строки |
| `m` в виде панели (наблюдение, история) | окно ввода для панели этого вида |

Клавиша в виде панели настраивается: `message_input.key` (`false` — не назначать).
Субагентам и фоновым командам писать нельзя: окно не открывается, плагин сообщает, что у
узла нет панели.

## Как отправить

- сохранение буфера: `:w` (также `:wq`, `:x`);
- Shift+Enter и Shift+Space — в нормальном режиме и в режиме вставки.

Текст уходит агенту одним сообщением, без изменений: переводы строк, пустые строки,
отступы, кавычки и кириллица сохраняются, текст не делится на части. После успешной
отправки окно закрывается. Пустой текст (или одни пробелы) не отправляется, окно остаётся.

Shift+Enter и Shift+Space терминал различает только с расширенным протоколом клавиатуры
(например, kitty keyboard protocol); без него работает `:w`. Клавиши отправки задаёт
настройка `message_input.send`.

## Что происходит после отправки

| Состояние агента | Результат |
|---|---|
| `idle` | сообщение отправлено, окно закрыто |
| `working` | сообщение принято в очередь агента: плагин сообщает об этом, окно закрыто |
| `blocked` | агент ждёт ответа на диалог; сообщение не отправляется, текст остаётся черновиком (см. ниже) |
| сервер недоступен или отказал | плагин показывает причину; окно и текст на месте, ничего не откладывается |

Если агент в состоянии `blocked` и у панели есть ждущий запрос (разрешение, вопрос, план),
открывается буфер диалога агента. Иначе плагин сообщает, что агент ждёт ответа, и
предлагает подключиться к панели с вводом (`:Claudr attach`); текст сообщения иным способом
не отправляется.

## Черновик

Закрытие окна без отправки (`:q`, закрытие окна) сохраняет набранный текст: при следующем
открытии окна для той же сессии он на месте. Черновики разных сессий хранятся раздельно.
После успешной отправки черновик очищается. Черновик живёт в памяти Neovim и между
запусками не сохраняется.

## Текст, начинающийся с «/» или «!»

Claude Code понимает начало `/` как команду, а `!` переводит поле ввода в режим оболочки.
По умолчанию плагин отправляет такой текст как есть и перед отправкой сообщает об этом.
Чтобы вставленный случайно текст не стал командой, включите защиту:

```lua
require("claudr").setup({
  message_input = { guard_commands = true },
})
```

С защитой к такому тексту добавляется ведущий пробел: ` /clear` Claude Code принимает как
обычное сообщение.

## Настройки

```lua
require("claudr").setup({
  message_input = {
    send = { "<S-CR>", "<S-Space>" }, -- клавиши отправки в окне ввода
    guard_commands = false,           -- ведущий пробел перед «/» и «!»
    key = "m",                        -- клавиша окна ввода в виде панели; false — нет
  },
})
```
