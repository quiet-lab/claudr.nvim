# `herdr agent attach` для панели без агента

## Вопрос

Работает ли `herdr agent attach <цель>` для панели, в которой нет агента
(обычная команда терминала). Нужна проверка с терминалом: команда открывает
двоичный протокол и занимает терминал.

## Что зависит от ответа

Спецификация `node-view`: подключение к панели с командой — живой терминал
или вывод по `pane.read` с обновлением по `pane.output_changed`. Пока вопрос
не решён, спецификация требует для панелей с командами только второй способ.
