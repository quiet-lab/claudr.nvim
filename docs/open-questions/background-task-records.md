# Записи фоновых задач Claude Code в нештатных случаях

## Вопрос

Как выглядят в транскрипте записи фоновой команды при ошибке, остановке и
для команды, пережившей сессию; как выглядят записи задач `Monitor` и
workflow. Проверен только пример с кодом выхода 0.

## Что зависит от ответа

Единый модуль разбора форматов Claude Code: вывод состояния «завершён с
ошибкой» и «остановлен» у фоновой команды, показ `Monitor` и workflow в дереве.
До ответа спецификация `agent-tree` описывает состояния «работает»,
«завершён» (с кодом выхода) и «оборван».
