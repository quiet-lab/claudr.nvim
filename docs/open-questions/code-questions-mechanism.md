# Механизм вопросов по коду

## Вопрос

Как вопрос по коду из Neovim доходит до Claude Code, а ответ возвращается в
интерфейс Neovim.

## Варианты

1. Собственный короткий процесс `claude -p` из Neovim. Не занимает панель и
   сессию herdr, не попадает в дерево; нарушает порядок «процессами владеет
   herdr» ([`../decisions/0001-herdr-owns-processes.md`](../decisions/0001-herdr-owns-processes.md)).
2. Отправка вопроса существующему инстансу через herdr (`agent.prompt`,
   ответ — из транскрипта сессии). Ответ идёт в сессию, занятую другой
   работой, и смешивается с ней.
3. Новая сессия в herdr (`session-launch`) с вопросом в качестве первого
   приглашения. Сессия видна в дереве; расход панели на каждый вопрос.

## Что зависит от ответа

Спецификация `code-questions`: источник ответа, жизненный цикл сессии вопроса,
отображение в дереве.

Решает пользователь.
