# Срок жизни файлов вывода фоновых команд

## Вопрос

Файлы вывода фоновых команд лежат в `/tmp/claude-<uid>/<проект>/<сессия>/tasks/`,
каталоги прошлых сессий удаляются. Что показывать для завершённой команды из
истории, когда файла вывода уже нет.

## Известно

В транскрипте остаются статус и код выхода команды; вывод — нет.

## Что зависит от ответа

Спецификации `node-view` (вывод фоновой команды из истории) и `session-history`.
