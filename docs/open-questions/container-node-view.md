# Вид workspace и вкладки при подключении

## Вопрос

Что показывает подключение к узлу-контейнеру (workspace или вкладка), у
которого нет собственного вывода: вывод одной панели, перечень панелей,
несколько видов сразу.

## Временное правило спецификации

Вкладка — вывод её первой по порядку панели; workspace — панели его активной
вкладки. Правило подлежит подтверждению пользователем.
