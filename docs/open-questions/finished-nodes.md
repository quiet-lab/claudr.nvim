# Показ завершённых узлов дерева

## Вопрос

Что делать в дереве с завершёнными субагентами и фоновыми командами: оставлять
на виду, сворачивать, скрывать по умолчанию, убирать по команде.

## Что зависит от ответа

Спецификация `agent-tree`: сейчас она требует лишь показывать завершённые узлы
с состоянием «завершён», пока жива их панель-владелец; отображение (свёртка,
фильтр) не определено.
