# Ссылки на файлы

В буферах плагина с содержимым Claude Code путь к файлу под курсором работает как ссылка:
его можно посмотреть в плавающем окне или открыть для правки, не набирая путь вручную.

## Где действуют ссылки

- вид наблюдения за панелью (`:Claudr view`);
- терминальный буфер подключения с вводом (`:Claudr attach`) — клавиши работают в нормальном
  режиме, после выхода из режима ввода терминала (`<C-\><C-n>`); терминал остаётся
  подключённым;
- транскрипт субагента и вывод фоновой команды;
- диалог из истории сессий ([история](history.md));
- окно ответа темы вопросов по коду ([вопросы по коду](code-questions.md)).

В остальных буферах клавиши не назначаются и работают как обычно.

## Что считается ссылкой

Путь абсолютный или относительный в одном из видов:

```
файл
файл:строка
файл:строка:столбец
```

Курсор может стоять на любом символе ссылки. Окружающие кавычки, обратные апострофы и
скобки, а также завершающие `.`, `,`, `;`, `:` в ссылку не входят: в тексте
(`lua/foo.lua:42`), ссылка — `lua/foo.lua`, строка 42.

Относительный путь отсчитывается от рабочего каталога сессии, которой принадлежит буфер:

| Буфер | Каталог |
|---|---|
| вид панели, подключение с вводом | рабочий каталог панели |
| транскрипт субагента, вывод фоновой команды | рабочий каталог панели-владельца |
| диалог из истории | рабочий каталог сессии (из её транскрипта) |
| окно ответа темы | каталог проекта темы |

Путь к несуществующему файлу и путь к каталогу ссылкой не считаются.

## Клавиши

| Клавиша | Что делает |
|---|---|
| `K` | предпросмотр: плавающее окно с файлом, строка ссылки выделена; фокус остаётся в буфере |
| `gd` | открыть файл в окне редактирования на строке и столбце ссылки |

Предпросмотр только для чтения, с подсветкой по типу файла. Если строка ссылки больше
числа строк файла, показывается последняя строка. Окно закрывается при движении курсора, при
выходе из буфера и по `<Esc>`.

`gd` открывает файл в окне с обычным буфером (сначала в предыдущем окне, затем в любом
другом); если такого окна нет, открывается новое. Буфер плагина остаётся на месте. Без строки
файл открывается с начала.

Если под курсором нет ссылки, клавиши работают как без плагина: сохраняется привязка,
назначенная в буфере раньше, затем глобальная, затем встроенное действие.

## Настройка

```lua
require("claudr").setup({
  file_references = {
    preview = "K",  -- клавиша предпросмотра
    open = "gd",    -- клавиша открытия
  },
})
```

Значение `false` отключает клавишу. Настройка читается при открытии буфера: уже открытые
буферы сохраняют прежние клавиши.
