# claudr.nvim

Плагин Neovim для управления клиентами Claude Code поверх уже работающего
сервера herdr (сборка с
расширенным API).

Плагин показывает дерево всего, что работает в herdr: workspace с
вложенностью, вкладки, панели с командами терминала и агентами, субагентов
сессий Claude Code и фоновые команды агентов и субагентов. К любому узлу
можно подключиться и увидеть его вывод, любому агенту можно написать из
Neovim, в любом workspace и любой вкладке можно запустить дополнительную
сессию Claude Code; доступны история сессий и вопросы по коду.

## Зависимости

- Neovim 0.12.
- Работающий сервер herdr с API сокета (протокол 22 и новее).
- Claude Code.
