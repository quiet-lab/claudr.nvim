## ADDED Requirements

### Requirement: Состав дерева
Дерево MUST содержать все workspace сервера herdr с вложенностью по `parent_workspace_id`, в каждом workspace — его вкладки, в каждой вкладке — её панели, в порядке `number`. Панели MUST входить в дерево независимо от того, кем они созданы, в том числе панели и вкладки, открытые агентами.

#### Scenario: Вложенный workspace
- **WHEN** в снимке workspace `w2` имеет `parent_workspace_id` равный `w1`
- **THEN** `w2` находится в дереве под `w1`

#### Scenario: Агент открыл новую вкладку
- **WHEN** агент в панели создаёт вкладку и запускает в ней другого агента
- **THEN** вкладка и её панель с агентом появляются в дереве без действий пользователя

### Requirement: Виды панелей
Панель MUST быть узлом одного из двух видов: «агент» (в снимке задан `agent`) или «команда» (агента нет). Подпись панели с агентом MUST содержать `display_agent` (при отсутствии — `agent`) и заголовок терминала, панели с командой — `foreground_process` и `cwd`.

#### Scenario: Панель с командой
- **WHEN** в панели без агента работает `cargo` в каталоге `/src`
- **THEN** узел имеет вид «команда» и подпись с `cargo` и `/src`

#### Scenario: Панель с агентом
- **WHEN** в снимке у панели `agent = "claude"` и `display_agent = "opus"`
- **THEN** узел имеет вид «агент», подпись содержит `opus` и заголовок терминала

### Requirement: Агенты других видов
Панель с агентом не Claude Code MUST показываться в дереве как панель с агентом, без субагентов и фоновых команд.

#### Scenario: Агент не Claude Code
- **WHEN** в панели работает агент другого вида
- **THEN** узел панели показывается без дочерних узлов субагентов и фоновых команд

### Requirement: Состояние панели с агентом
Узел панели с агентом MUST показывать состояние `agent_status` из herdr (`unknown`, `idle`, `working`, `blocked`) и MUST менять его по событию `pane.agent_status_changed`. Неизвестное значение MUST показываться как есть.

#### Scenario: Агент ждёт ответа
- **WHEN** приходит `pane.agent_status_changed` с `agent_status = blocked`
- **THEN** узел панели показывает состояние `blocked`

#### Scenario: Агент вышел
- **WHEN** агент завершил работу, и панель вернулась к оболочке (`agent_status = unknown`, `agent` не задан)
- **THEN** узел панели показывается как панель с командой, без субагентов и фоновых команд

### Requirement: Субагенты панели
Под узлом панели с агентом Claude Code MUST находиться субагенты его сессии, полученные от модуля `claude-code-data` по `agent_session.value`. Субагент первого уровня MUST быть дочерним узлом панели, вложенный (с `parentAgentId`) — дочерним узлом своего родителя. Подпись субагента MUST содержать `description` и `agentType`.

#### Scenario: Вложенные субагенты
- **WHEN** субагент B имеет `parentAgentId`, равный идентификатору субагента A
- **THEN** B находится под A, A — под панелью владельца

### Requirement: Панель без известной сессии
Панель, для которой транскрипт не найден или `agent_session` не задан, MUST показываться без субагентов и фоновых команд; когда сессия становится известна (`pane.updated`), они MUST появляться.

#### Scenario: Сессия ещё не известна
- **WHEN** у панели нет `agent_session`
- **THEN** узел панели показывается без дочерних узлов, а после `pane.updated` с заполненным `agent_session` дерево получает субагентов сессии

### Requirement: Фоновые команды
Под узлом владельца (панели с агентом или субагента) MUST находиться его фоновые команды: команда MUST находиться под тем владельцем, в чьём транскрипте записан её вызов. Подпись команды MUST содержать `description` (при отсутствии — `command`).

#### Scenario: Команда агента
- **WHEN** в транскрипте сессии есть вызов фоновой команды
- **THEN** под узлом панели есть узел команды с подписью из `description`

#### Scenario: Команда субагента
- **WHEN** вызов фоновой команды записан в транскрипте субагента
- **THEN** узел команды находится под узлом этого субагента, а не под панелью

### Requirement: Состояния субагентов и команд
Субагент и фоновая команда MUST иметь одно из состояний «работает», «завершён», «оборван», выводимое по правилам `claude-code-data`. Код выхода завершённой команды MUST показываться в подписи; остановленный (статус `killed`) показывается как «завершён» с пометкой остановки.

#### Scenario: Работающий субагент
- **WHEN** у субагента нет отметки завершения, а панель владельца жива
- **THEN** состояние субагента «работает»

#### Scenario: Завершение фоновой команды
- **WHEN** модуль сообщает отметку завершения команды с кодом выхода 0
- **THEN** состояние команды «завершён», подпись содержит код выхода 0

#### Scenario: Остановленная команда
- **WHEN** модуль сообщает, что команда остановлена
- **THEN** состояние команды «завершён», подпись содержит пометку остановки

#### Scenario: Упавший владелец
- **WHEN** у субагента нет отметки завершения и приходит `pane_exited` панели владельца
- **THEN** субагент и его команды без отметки завершения получают состояние «оборван»

### Requirement: Завершённые узлы
Завершённые субагенты и фоновые команды MUST оставаться в дереве с состоянием «завершён» до закрытия панели владельца. Показ завершённых узлов MUST переключаться командой; состояние переключателя — настройка `show_finished` со значением по умолчанию «показывать».

#### Scenario: Завершённый узел остаётся
- **WHEN** субагент завершён, а панель владельца жива
- **THEN** узел остаётся в дереве с состоянием «завершён»

#### Scenario: Скрытие завершённых
- **WHEN** пользователь переключает показ завершённых узлов
- **THEN** завершённые субагенты и команды скрываются, работающие и оборванные остаются

#### Scenario: Закрытие панели владельца
- **WHEN** панель владельца закрыта
- **THEN** узлы субагентов и команд этой панели исчезают из дерева вместе с ней

### Requirement: Обновление по событиям
Дерево MUST обновляться по событиям: структура и состояния панелей — по событиям herdr, субагенты и фоновые команды — по уведомлениям модуля `claude-code-data`. Дерево MUST NOT использовать таймеры и периодическое чтение.

#### Scenario: Новый субагент
- **WHEN** сессия запускает субагента и модуль сообщает о нём
- **THEN** узел субагента появляется в дереве без действий пользователя

#### Scenario: Ничего не происходит
- **WHEN** событий herdr и файловой системы нет
- **THEN** плагин не читает ни сокет, ни файлы Claude Code
