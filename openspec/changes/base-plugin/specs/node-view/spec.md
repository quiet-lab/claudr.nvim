## ADDED Requirements

### Requirement: Подключение к любому узлу
К любому узлу дерева MUST быть возможно подключиться и увидеть вывод узла в данный момент. Способ определяется видом узла и описан в требованиях ниже.

#### Scenario: Выбор узла
- **WHEN** пользователь выбирает узел дерева и вызывает подключение
- **THEN** открывается вид, соответствующий виду узла

### Requirement: Панель с агентом — живой терминал
Подключение к панели с агентом MUST открывать в буфере терминала Neovim живое подключение к терминалу агента (`herdr agent attach <цель>`): вывод агента виден, ввод пользователя уходит агенту.

#### Scenario: Подключение к агенту
- **WHEN** пользователь подключается к панели с агентом Claude Code
- **THEN** в Neovim открывается буфер терминала с интерфейсом агента, набранный текст попадает в агента

### Requirement: Панель с командой — вывод с обновлением
Подключение к панели с командой MUST показывать её вывод, прочитанный `pane.read` (источник `recent_unwrapped`), только для чтения. Вид MUST перечитываться по событию `pane.output_changed` панели, без таймеров и опроса. Подключение к терминалу панели без агента через `herdr agent attach` MUST NOT применяться, пока вопрос о нём не решён ([`docs/open-questions/attach-without-agent.md`](../../../../docs/open-questions/attach-without-agent.md)).

#### Scenario: Команда печатает вывод
- **WHEN** в подключённой панели с командой появляется новый вывод и приходит `pane.output_changed`
- **THEN** вид перечитывает панель и показывает новый вывод

#### Scenario: Правка вида
- **WHEN** пользователь пытается изменить текст вида панели с командой
- **THEN** изменение отвергается, панель не получает ввода

### Requirement: Субагент — транскрипт по мере записи
Подключение к субагенту MUST показывать его транскрипт `agent-<id>.jsonl`, только для чтения, с дополнением по мере записи: новые строки читаются с запомненного смещения по уведомлению файловой системы. Реплики MUST разбираться модулем разбора форматов Claude Code, а не показываться сырыми строками JSON.

#### Scenario: Работающий субагент
- **WHEN** подключён вид работающего субагента и в транскрипт дописывается реплика
- **THEN** реплика появляется в виде без действий пользователя

#### Scenario: Завершённый субагент
- **WHEN** подключён вид завершённого субагента
- **THEN** показан весь транскрипт, новых дополнений нет

### Requirement: Фоновая команда — файл вывода
Подключение к фоновой команде MUST показывать её файл вывода, только для чтения, с дополнением по мере записи по уведомлению файловой системы. Если файла вывода уже нет, вид MUST сообщать об этом, показывая статус и код выхода из транскрипта.

#### Scenario: Команда ещё работает
- **WHEN** подключён вид работающей команды, и она дописывает файл вывода
- **THEN** новый вывод появляется в виде без действий пользователя

#### Scenario: Файл вывода удалён
- **WHEN** команда завершена, а каталог `tasks/` её сессии удалён
- **THEN** вид сообщает, что вывод недоступен, и показывает статус и код выхода

### Requirement: Узлы-контейнеры
Подключение к вкладке MUST открывать вид её первой по порядку панели, подключение к workspace — вид первой по порядку панели его активной вкладки; вид выбирается по виду панели по требованиям выше. Правило временное: [`docs/open-questions/container-node-view.md`](../../../../docs/open-questions/container-node-view.md).

#### Scenario: Вкладка с панелью команды
- **WHEN** пользователь подключается к вкладке, первая панель которой — панель с командой
- **THEN** открывается вид вывода этой панели

### Requirement: Отсутствие таймеров и опроса в видах
Обновление видов MUST идти по событиям (`pane.output_changed`, уведомления файловой системы); таймеры и опрос MUST NOT использоваться.

#### Scenario: Тишина в панели
- **WHEN** панель с командой не меняет вывод
- **THEN** плагин не вызывает `pane.read`
