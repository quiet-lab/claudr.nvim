## ADDED Requirements

### Requirement: Вопрос по выделению
Пользователь MUST иметь возможность задать вопрос по выделенному в Neovim фрагменту: в вопрос MUST входить текст вопроса, путь файла, диапазон строк выделения и текст выделения.

#### Scenario: Вопрос по выделению
- **WHEN** пользователь выделяет строки 10–20 файла `lua/foo.lua` и вводит вопрос
- **THEN** в вопрос уходят текст вопроса, путь `lua/foo.lua`, диапазон 10–20 и текст выделенных строк

### Requirement: Вопрос по файлу
Пользователь MUST иметь возможность задать вопрос по текущему файлу без выделения: в вопрос MUST входить текст вопроса и путь файла; содержимое файла MUST уходить как есть, включая несохранённые правки буфера.

#### Scenario: Вопрос по файлу
- **WHEN** пользователь вызывает вопрос по файлу и вводит текст
- **THEN** в вопрос уходят текст вопроса и путь файла, ответ MAY ссылаться на содержимое буфера

### Requirement: Ответ в интерфейсе Neovim
Ответ MUST показываться пользователю в интерфейсе Neovim, только для чтения, и MUST оставаться доступным после закрытия окна ответа до закрытия Neovim или явного удаления.

#### Scenario: Показ ответа
- **WHEN** ответ на вопрос получен
- **THEN** пользователь видит его в окне Neovim и может открыть его снова после закрытия окна

### Requirement: Ошибка доставки
Если вопрос не удалось доставить или ответ не получен, плагин MUST сообщить причину; текст вопроса MUST оставаться доступным для повторной отправки.

#### Scenario: Доставка не удалась
- **WHEN** механизм доставки возвращает ошибку
- **THEN** пользователь видит причину, вопрос можно отправить повторно без повторного ввода

### Requirement: Отсутствие таймеров и опроса
Получение ответа MUST идти по событиям (выход процесса, события herdr, уведомления файловой системы); таймеры и опрос MUST NOT использоваться.

#### Scenario: Ожидание ответа
- **WHEN** ответ ещё не получен
- **THEN** плагин не выполняет периодических проверок
