## ADDED Requirements

### Requirement: Выбор workspace и вкладки
Целью запуска MUST быть workspace и вкладка, выбранные пользователем: узлом дерева или из перечня через `vim.ui.select`.

#### Scenario: Выбор из перечня
- **WHEN** пользователь вызывает запуск без выбранного узла
- **THEN** плагин предлагает перечень workspace через `vim.ui.select`

### Requirement: Новая сессия в новой вкладке
Пользователь MUST иметь возможность запустить дополнительную сессию Claude Code в выбранном workspace: плагин MUST создать вкладку (`tab.create`) и запустить агента вида `claude` (`agent.start`) в корневой панели созданной вкладки.

#### Scenario: Запуск в workspace
- **WHEN** пользователь выбирает workspace и запускает сессию в новой вкладке
- **THEN** сервер получает `tab.create` для этого workspace, затем `agent.start` с видом `claude` и панелью `root_pane` из ответа

### Requirement: Новая сессия делением панели
Пользователь MUST иметь возможность запустить дополнительную сессию в выбранной вкладке делением панели: плагин MUST разделить панель, выбранную пользователем (узел панели или строка из перечня панелей вкладки), методом `pane.split` и запустить агента вида `claude` в новой панели.

#### Scenario: Запуск делением
- **WHEN** пользователь выбирает панель, направление деления и запускает сессию
- **THEN** сервер получает `pane.split` для этой панели, затем `agent.start` с видом `claude` для созданной панели

### Requirement: Рабочий каталог
Плагин MUST NOT передавать рабочий каталог при создании вкладки и деления: действует значение herdr по умолчанию.

#### Scenario: Запуск без каталога
- **WHEN** плагин создаёт вкладку
- **THEN** в запросе `tab.create` нет поля `cwd`

### Requirement: Запуск без блокировки Neovim
Ожидание готовности агента (`agent.start` отвечает, когда агент готов к вводу) MUST происходить асинхронно: Neovim MUST оставаться отзывчивым, о результате MUST сообщаться после ответа сервера.

#### Scenario: Долгий запуск
- **WHEN** агент запускается долго
- **THEN** пользователь продолжает работать в Neovim, а по готовности получает сообщение

### Requirement: Ошибки запуска
Если `tab.create`, `pane.split` или `agent.start` завершаются ошибкой, плагин MUST показать код и текст ошибки сервера. Созданные к этому моменту вкладка или панель MUST оставаться как есть: плагин их не закрывает.

#### Scenario: Агент не запустился
- **WHEN** `tab.create` выполнен, а `agent.start` возвращает ошибку
- **THEN** пользователь видит ошибку, созданная вкладка остаётся открытой

### Requirement: Новая сессия в дереве
Запущенная сессия MUST появляться в дереве по событиям herdr (`pane.created`, `pane.agent_detected`), без специальной обработки результата запуска.

#### Scenario: Появление узла
- **WHEN** после `agent.start` приходят `pane.created` и `pane.agent_detected`
- **THEN** дерево содержит узел новой панели с агентом

### Requirement: Сервер недоступен
Если сервера нет, запуск MUST завершаться сообщением о недоступности сервера.

#### Scenario: Запуск без сервера
- **WHEN** пользователь запускает сессию, а сервера herdr нет
- **THEN** плагин сообщает о недоступности сервера и ничего не создаёт
