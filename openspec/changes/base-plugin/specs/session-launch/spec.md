## ADDED Requirements

### Requirement: Новая сессия в новой вкладке
Пользователь MUST иметь возможность запустить дополнительную сессию Claude Code в любом workspace: плагин MUST создать вкладку в выбранном workspace (`tab.create`) и запустить агента вида `claude` (`agent.start`) в корневой панели созданной вкладки.

#### Scenario: Запуск в workspace
- **WHEN** пользователь выбирает workspace и запускает сессию в новой вкладке
- **THEN** сервер получает `tab.create` для этого workspace, затем `agent.start` с видом `claude` и панелью `root_pane` из ответа, и новая панель с агентом появляется в дереве

### Requirement: Новая сессия делением панели
Пользователь MUST иметь возможность запустить дополнительную сессию в любой вкладке делением панели: плагин MUST разделить панель вкладки (`pane.split`) и запустить агента вида `claude` в новой панели.

#### Scenario: Запуск делением
- **WHEN** пользователь выбирает вкладку, направление деления и запускает сессию
- **THEN** сервер получает `pane.split` для панели этой вкладки, затем `agent.start` с видом `claude` для созданной панели

### Requirement: Запуск без блокировки Neovim
Ожидание готовности агента (`agent.start` отвечает, когда агент готов к вводу) MUST происходить асинхронно: Neovim MUST оставаться отзывчивым, а о результате MUST сообщаться после ответа сервера.

#### Scenario: Долгий запуск
- **WHEN** агент запускается долго
- **THEN** пользователь продолжает работать в Neovim, а по готовности получает сообщение

### Requirement: Ошибки запуска
Если `tab.create`, `pane.split` или `agent.start` завершаются ошибкой, плагин MUST показать код и текст ошибки сервера. Созданные к этому моменту вкладка или панель MUST оставаться как есть: плагин их не закрывает.

#### Scenario: Агент не запустился
- **WHEN** `tab.create` выполнен, а `agent.start` возвращает ошибку
- **THEN** пользователь видит ошибку, созданная вкладка остаётся открытой

### Requirement: Новая сессия в дереве
Запущенная сессия MUST появляться в дереве по событиям herdr (`pane.created`, `pane.agent_detected`), без специальной обработки результата запуска.

#### Scenario: Появление узла
- **WHEN** после `agent.start` приходят `pane.created` и `pane.agent_detected`
- **THEN** дерево содержит узел новой панели с агентом

### Requirement: Сервер недоступен
Если сервера нет, запуск MUST завершаться сообщением о недоступности сервера.

#### Scenario: Запуск без сервера
- **WHEN** пользователь запускает сессию, а сервера herdr нет
- **THEN** плагин сообщает о недоступности сервера и ничего не создаёт
