## Why

Сессии Claude Code работают в панелях herdr, а из Neovim не видны: нет общего
дерева workspace, вкладок, панелей, субагентов и фоновых команд, нельзя
подключиться к узлу, написать агенту, запустить дополнительную сессию,
открыть историю или задать вопрос по коду, не выходя из редактора. Плагин
claudr.nvim даёт это поверх уже работающего сервера herdr: процессами агентов
владеет herdr, плагин — его клиент по сокету API (решение D1 в `design.md`).

## What Changes

Базовый набор возможностей плагина, восемь спецификаций:

- `claude-code-data` — чтение данных Claude Code одним модулем: транскрипты,
  субагенты, фоновые команды, слежение за файлами.
- `herdr-client` — подключение к сокету API herdr, снимок, подписка на события,
  проверка протокола, недоступный и перезапущенный сервер.
- `agent-tree` — дерево workspace, вкладок, панелей, субагентов и фоновых
  команд с состояниями «работает», «завершён», «оборван».
- `node-view` — подключение к любому узлу дерева и просмотр его вывода.
- `messaging` — сообщения и клавиши из Neovim агентам; субагентам и фоновым
  командам писать нельзя.
- `session-launch` — дополнительная сессия Claude Code в любом workspace и
  любой вкладке.
- `session-history` — перечень сессий проекта инстанса и просмотр диалога.
- `code-questions` — вопросы по коду в темах: отдельные сессии Claude Code,
  запущенные плагином, реестр тем, точки расширения.

Кода и тестов это изменение не содержит: сначала утверждаются спецификации.

## Capabilities

### New Capabilities

- `claude-code-data`: чтение данных Claude Code.
- `herdr-client`: клиент сокета API herdr.
- `agent-tree`: дерево узлов и их состояния.
- `node-view`: просмотр вывода узла.
- `messaging`: отправка сообщений и клавиш.
- `session-launch`: запуск дополнительной сессии Claude Code.
- `session-history`: история сессий и перечень тем.
- `code-questions`: вопросы по коду.

### Modified Capabilities

Нет.

## Out of Scope

В изменение не входят, и решения по ним пользователем не приняты:

- пометки тем вопросов по коду на строках кода;
- хранение тем дольше срока хранения транскриптов Claude Code;
- режим обучения (в изменении только точки расширения вопросов по коду);
- пакеты языков (то же);
- выбор базы знаний для источника знаний;
- механика ответвления от базовой сессии проекта: создание и обновление
  базовой сессии (в изменении только настройка, по умолчанию выключенная);
- запись в субагентов и фоновые команды.

## Impact

Новый плагин Neovim 0.12 и новее; зависит от работающего сервера herdr
(протокол 22 и новее) и Claude Code. Файлы Claude Code плагин только читает;
в herdr он создаёт вкладки, панели и сессии только по команде пользователя.
Для вопросов по коду плагин сам запускает процессы `claude -p`.
