## Why

Пользователь сравнил дерево с боковой панелью herdr и дал три замечания: анимация луны
идёт не так, как в herdr; вместо эмодзи виден маленький кружок из шрифта; есть узлы, у
которых вместо подписи единичка. Требование пользователя — дерево должно выглядеть и
вести себя как боковая панель herdr.

Причины:

- кадры всех работающих строк общие (решение D39), а herdr при `frame_phase = "per_row"`
  сдвигает начало кадров каждой строки и меняет её период в пределах
  `frame_speed_spread`;
- единственная вкладка workspace показана отдельной строкой с подписью-номером («1»),
  которую herdr не показывает нигде; вкладка с ручным именем, повторяющим workspace,
  даёт дубль; ручное имя вкладки без агента («▸ …») herdr заменяет автоматической
  подписью;
- субагент без описания подписан идентификатором;
- маленький кружок — глиф основного шрифта Neovide: шрифт содержит фазы луны
  (U+1F311…U+1F318) и `🆘` одноцветными знаками, а Neovide выбирает шрифт по наличию
  глифа, не по свойству «эмодзи по умолчанию». Это не исправляется плагином (см. design).

## What Changes

- Кадр значка — по часам строки, как в herdr: при `per_row` у каждой строки свой сдвиг
  начала и свой период; таймер остаётся один, на ближайшую границу среди строк.
- Клиент читает `frame_phase` и `frame_speed_spread` из `[ui.status_icons]`.
- Единственная вкладка workspace не показывается строкой: её панели стоят под workspace.
- Подпись вкладки — по правилу herdr: ручное имя, пока во вкладке есть агент и имя не
  повторяет workspace, иначе «<символ> <место> · <приложение>».
- Подпись субагента без описания — описание вызова Agent или первая строка задания из
  транскрипта, без них — тип агента.

## Capabilities

### Modified Capabilities

- `agent-tree`: состав дерева (единственная вкладка), подписи вкладок, подпись
  субагента, кадр анимации по часам строки.
- `herdr-client`: чтение `frame_phase` и `frame_speed_spread`.
- `claude-code-data`: задание субагента и описание из вызова Agent.
