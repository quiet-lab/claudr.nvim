## MODIFIED Requirements

### Requirement: Состав дерева
Дерево MUST содержать все workspace сервера herdr с вложенностью по `parent_workspace_id`, в каждом workspace — его вкладки, в каждой вкладке — её панели, в порядке `number`. Панели MUST входить в дерево независимо от того, кем они созданы. В режиме `icons = "herdr"` единственная вкладка workspace MUST NOT показываться строкой: её панели MUST стоять прямо под workspace.

#### Scenario: Вложенный workspace
- **WHEN** в снимке workspace `w2` имеет `parent_workspace_id` равный `w1`
- **THEN** `w2` находится в дереве под `w1`

#### Scenario: Агент открыл новую вкладку
- **WHEN** агент в панели создаёт вкладку и запускает в ней другого агента
- **THEN** вкладка и её панель с агентом появляются в дереве без действий пользователя

#### Scenario: Единственная вкладка
- **WHEN** у workspace `w1` одна вкладка `w1:t1` с панелью `w1:p1`
- **THEN** строки `w1:t1` нет, строка `w1:p1` стоит под строкой `w1`; в режиме `icons = "text"` строка `w1:t1` есть

### Requirement: Субагенты панели
Под узлом панели с агентом Claude Code MUST находиться субагенты его сессии, полученные от модуля `claude-code-data` по `agent_session.value`. Субагент первого уровня MUST быть дочерним узлом панели, вложенный (с `parentAgentId`) — дочерним узлом своего родителя. Подпись субагента MUST состоять из описания (без него — первой строки задания, не длиннее 60 символов) и `agentType` в скобках; без описания и задания — из `agentType`, без всего — из идентификатора.

#### Scenario: Вложенные субагенты
- **WHEN** субагент B имеет `parentAgentId`, равный идентификатору субагента A
- **THEN** B находится под A, A — под панелью владельца

#### Scenario: Субагент без описания
- **WHEN** у субагента нет описания, задание начинается строкой `Проверить ветку`, `agentType = "general-purpose"`
- **THEN** подпись — `Проверить ветку (general-purpose)`, а без задания — `general-purpose`

### Requirement: Подписи workspace и вкладок
Подпись workspace MUST состоять из символа `tokens.symbol` и `label` через пробел; без токена или при `label`, начинающемся с символа, — из `label`. Подпись вкладки MUST быть её `label`, если он отличен от номера вкладки, во вкладке есть агент и он не повторяет подпись workspace; иначе — «<символ> <место> · <приложение>» без недостающих частей, без места и приложения — `label`. Подписи workspace, вкладок и панелей с агентом MUST иметь цвет `tokens.color` (`#RGB`/`#RRGGBB`), иначе цвет обычный.

#### Scenario: Символ и цвет
- **WHEN** у workspace `label = "demo"`, `tokens = {symbol = "S1", color = "#336699"}`
- **THEN** подпись — `S1 demo`, она и подписи его вкладок и панелей с агентом окрашены `#336699`

#### Scenario: Токенов нет
- **WHEN** у workspace в снимке нет `tokens`
- **THEN** подпись — `label`, цвет подписи обычный

#### Scenario: Не цвет
- **WHEN** `tokens.color = "red"`
- **THEN** подписи показываются обычным цветом, ошибки нет

#### Scenario: Вкладка без имени
- **WHEN** у вкладки `number = 1`, `label = "1"`, в ней панель агента `opus` с каталогом `/x/proj` вне репозитория, символ workspace `S1`
- **THEN** подпись вкладки — `S1 proj · opus`

#### Scenario: Ручное имя без агента
- **WHEN** у вкладки `label = "▸ notes"`, в ней только оболочка `bash` с каталогом `/x/notes`
- **THEN** подпись вкладки — `S1 notes · bash`

#### Scenario: Имя повторяет workspace
- **WHEN** вкладка с агентом названа так же, как её workspace
- **THEN** подпись вкладки автоматическая, дубля подписи workspace нет

### Requirement: Кадр анимации
Кадр значка MUST быть функцией монотонных часов и часов строки, как в herdr: при `frame_phase = "per_row"` период строки — период состояния, умноженный на коэффициент от `1 − spread` до `1 + spread`, а сдвиг начала — в пределах круга кадров, оба по идентификатору узла; иначе сдвиг 0 и период состояния. Номер кадра — целая часть от (время + сдвиг) / период по модулю числа кадров. Смена кадра MUST менять только метки значков, не текст буфера, модель и курсор.

#### Scenario: Смена кадра
- **WHEN** кадры общие и срабатывание вызвано напрямую с временем, больше прежнего на один период
- **THEN** у каждой строки `working` показан следующий кадр, по кругу после последнего

#### Scenario: Кадр по часам
- **WHEN** кадры общие и срабатывание вызвано со временем, равным пяти периодам, а кадров три
- **THEN** показан кадр с номером 2 (счёт с нуля)

#### Scenario: Кадры строк со сдвигом
- **WHEN** `frame_phase = "per_row"`, `frame_speed_spread = { working = 0.10 }`, а две панели `w1:p1` и `w1:p2` в состоянии `working`
- **THEN** их часы совпадают с часами herdr для тех же идентификаторов, кадры строк в разные моменты различаются, а таймер один и стоит на ближайшей границе среди строк

#### Scenario: Только значки
- **WHEN** срабатывание сменило кадр
- **THEN** строки буфера, список узлов и положение курсора прежние, изменены только метки значков анимируемых строк
