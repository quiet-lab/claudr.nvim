## Context

Факты о herdr установлены по исходникам форка (пути — относительно его репозитория) и по
ответу рабочего сервера на `session.snapshot`; других запросов к серверу не делалось.

- Кадр значка (`src/client/shell/status_frames.rs`): у каждой строки свои часы — период
  `frame_interval_ms × k` и сдвиг начала. При `frame_phase = "per_row"` начальное значение
  строки — `row_phase(ключ машины, идентификатор)`: FNV-1a 64 по ключу машины, байту `0xff` и
  идентификатору, затем перемешивание splitmix64. Коэффициент `k` (в тысячных) равен
  `1000 − spread + (seed >> 32) mod (2·spread + 1)`, сдвиг — `seed mod (период × число
  кадров)`; кадр — `⌊(t + сдвиг) / период⌋ mod число кадров`. Для локального сервера ключ
  машины пустой, идентификатор — `pane_id` у строки агента и `workspace_id` у строки
  workspace. При `synced` (по умолчанию) сдвиг 0 и `k = 1`. Границы строк ближе 2 мс
  обслуживаются одним пробуждением.
- Подписи (`src/client/shell/labels.rs`, `src/auto_label.rs`): ручное имя вкладки
  показывается, только пока во вкладке обнаружен агент; иначе — «<символ> <место> ·
  <приложение>» без недостающих частей. Место — имя репозитория Git корневой панели или
  имя её каталога (не путь), приложение — агент вкладки, без него — процесс панели в фокусе.
  Токен `tab` у единственной вкладки без ручного имени не показывается: она повторяет
  workspace (`tab_token_shown`).
- API-снимок отдаёт у вкладки только `label`, `number`, `agent_status`; признака ручного
  имени (`custom_label`) и фактов `place`, `agent_label` в нём нет. Имя вкладки без ручного
  имени равно её номеру.
- Значок `🌑` в Neovide: основной шрифт пользователя (Iosevka Nerd Font) содержит фазы луны
  U+1F311…U+1F318 и `🆘` (U+1F198) одноцветными знаками; `🍀`, `🤖`, `☕`, `🗿` в нём нет.
  Neovide (`src/renderer/fonts/caching_shaper.rs`) выбирает первый шрифт, покрывающий
  кластер; вариационный селектор U+FE0F библиотека swash из кластера исключает, поэтому он
  выбор шрифта не меняет. WezTerm для символов со свойством «эмодзи по умолчанию» берёт
  цветной шрифт, поэтому в терминале значки — эмодзи.

## Goals / Non-Goals

**Goals:** кадры значков и подписи вкладок — как в herdr; ни одной строки с подписью-номером
и ни одного дубля «workspace → вкладка с той же подписью»; осмысленная подпись субагента.

**Non-Goals:** выбор шрифта в Neovide; правка herdr, его протокола и конфигурации; второй
таймер.

## Decisions

Нумерация продолжает `tree-look` (D36–D44).

### D45. Часы строки, как в herdr

*Заменяет D39 в части синхронных кадров.* В условиях, когда herdr при `frame_phase =
"per_row"` разводит строки по фазе и скорости, а пользователь сравнивает дерево с его
боковой панелью, учитывая, что кадр строки — чистая функция часов и идентификатора, выбрано
читать `frame_phase` и `frame_speed_spread` из `[ui.status_icons]` и считать часы строки тем
же расчётом, что `status_frames.rs` (FNV-1a 64, splitmix64, пустой ключ машины,
идентификатор узла), а единственный таймер ставить на ближайшую границу среди показанных
строк с окном слияния 2 мс, чтобы анимация совпадала с herdr, ценой пробуждений таймера
чаще, чем раз в период. Метка значка переставляется, только когда кадр строки сменился.
Разброс вне 0…0.5 читается как 0 (herdr такой файл отвергает целиком). Без LuaJIT FFI
начальное значение — 32-битное того же назначения.

### D46. Единственная вкладка и подпись вкладки

*Заменяет D43 в части подписи вкладки.* В условиях, когда единственная вкладка workspace
давала строку с подписью-номером («1») или повторяла подпись workspace, учитывая, что herdr
такую вкладку не подписывает, а ручное имя показывает только при агенте, выбрано: в режиме
`icons = "herdr"` единственную вкладку строкой не показывать (её панели стоят под
workspace, модель не меняется); подпись вкладки — ручное имя, пока во вкладке есть агент и
имя не повторяет подпись workspace, иначе «<символ workspace> <место> · <приложение>», где
место — имя репозитория Git каталога первой панели или имя каталога, приложение — агент
панели в фокусе или любой панели вкладки, без агента — процесс панели в фокусе (без фокуса —
первой); ручным считается имя, отличное от номера вкладки, чтобы дерево читалось как herdr,
ценой поиска каталога `.git` при первом показе каталога (ответ запоминается до остановки
модели) и того, что вкладка, вручную названная своим номером, считается безымянной. Режим
`icons = "text"` показывает все уровни, как раньше (D42). Курсор, поставленный на скрытую
вкладку (`focus`), встаёт на её workspace. Подпись workspace не меняется (D43): ручное имя
workspace от автоматического по снимку не отличить.

### D47. Подпись субагента без описания

В условиях, когда субагенты, запущенные навыками, не имеют `description` в `meta.json` и
подписывались идентификатором, выбрано брать описание из вызова `Agent` владельца по
`toolUseId`, без него — первую непустую строку задания (первой записи транскрипта
субагента, не длиннее 60 символов), без неё — тип агента, и только без всего —
идентификатор, чтобы строка субагента говорила, что он делает, ценой чтения одной лишней
записи транскрипта при первом чтении.

### D48. Значок из основного шрифта Neovide не исправляется плагином

В условиях, когда Neovide берёт фазы луны из основного шрифта, а селектор U+FE0F выбор
шрифта не меняет, учитывая запрет правки конфигурации пользователя и herdr, выбрано значки
не подменять и описать причину и проверку в `docs/tree.md`, чтобы плагин не расходился с
herdr по набору значков, ценой одноцветных фаз луны в Neovide до смены шрифта или значков
пользователем. Отвергнуто: добавлять U+FE0F (swash его отбрасывает; D41), подменять значки в
Neovide (второе место настройки, отвергнуто в D37).

## Risks / Trade-offs

- Пробуждения таймера: при `per_row` с разбросом границы строк не совпадают, таймер
  срабатывает до числа строк раз за период; перерисовываются только сменившиеся метки.
- Поиск `.git` идёт по локальной файловой системе: для удалённого сервера место может
  оказаться именем каталога.
- Вкладка, вручную названная своим номером, получает автоматическую подпись.
