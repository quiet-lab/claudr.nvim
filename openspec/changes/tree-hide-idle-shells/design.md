## Context

Решение пользователя: панели с простаивающей оболочкой в дерево не попадают. Строка
`💻 bash <каталог>` такой панели читается как сценарий `bash <путь>`. Механизм скрытия панели
без строки уже есть: панель с Neovim на переднем плане и агент вкладки получают узел с
`hidden = true` (D58, D60), который остаётся в модели и доступен по идентификатору панели.

**Приоритеты:** решение пользователя; наименьший объём правки, существующий механизм скрытия
прежде нового; без таймеров и опроса.

## Decisions

### D67. Панель с простаивающей оболочкой — без строки

В условиях, когда строка простаивающей оболочки читается как сценарий, учитывая решение
пользователя и готовый механизм скрытых панелей, выбрано: панель с командой, у которой
`foreground_process` — оболочка, получает узел с `hidden = true`, как панель с Neovim;
вкладка остаётся строкой, её `target_pane` по-прежнему выбирается из всех панелей вкладки,
поэтому Enter на вкладке без агента открывает терминал такой панели. Чтобы не вводить новый
путь видимости и не менять действия по идентификатору панели, ценой того, что работающую
в панели программу, которая сама является оболочкой (например, вложенный `bash
script.sh`), herdr отдаёт как оболочку, и её панель тоже остаётся без строки.

Перечень оболочек — имена процесса: `bash`, `zsh`, `fish`, `sh`, `dash`, `ksh`, `mksh`,
`tcsh`, `csh`, `nu`, `xonsh`, `elvish`. Ведущий `-` login-оболочки (`-bash`)
отбрасывается перед сравнением. Панель без `foreground_process` строкой остаётся:
признака оболочки нет.

Отличить простаивающую оболочку от выполняющей команду по снимку можно: herdr отдаёт в
`foreground_process` имя процесса группы переднего плана терминала, а при запуске команды
группой переднего плана становится процесс команды. Проверено на рабочем сервере: в
панелях агентов процесс `claude` — дочерний процесс оболочки `bash`, и снимок отдаёт
`foreground_process = "claude"`; у простаивающих оболочек — `bash`.

### Событие смены программы на переднем плане

Сервер herdr при смене программы на переднем плане публикует `pane.updated`
(`src/app/api.rs` форка herdr: `ForegroundProcessChanged` с изменившимся именем вызывает
`emit_pane_updated`). Клиент плагина подписан на `pane.updated` и по нему перечитывает
`session.snapshot`, поэтому появление и уход команды меняют дерево по событию, без опроса.
