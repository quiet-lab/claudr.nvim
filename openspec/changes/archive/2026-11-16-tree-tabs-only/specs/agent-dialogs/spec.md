## MODIFIED Requirements

### Requirement: Приём запроса и привязка к узлу
Плагин MUST принимать запрос, только если `HERDR_SOCKET_PATH` запроса совпадает с сервером herdr плагина, а `HERDR_PANE_ID` — панель из снимка этого сервера; иначе MUST закрыть соединение без ответа. Запрос с `agent_id` MUST привязываться к узлу этого субагента, если он есть в дереве, иначе к строке агента панели; запрос без `agent_id` — к строке агента панели. Строка агента — строка прочего агента вкладки, если панель не агент вкладки, иначе строка вкладки (при скрытой единственной вкладке — строка workspace).

#### Scenario: Чужой сервер
- **WHEN** `HERDR_SOCKET_PATH` запроса указывает на другой сервер herdr
- **THEN** плагин закрывает соединение, запрос в перечень не попадает

#### Scenario: Запрос субагента
- **WHEN** запрос содержит `agent_id` субагента, узел которого есть под вкладкой
- **THEN** запрос привязан к узлу субагента

#### Scenario: Запрос агента вкладки
- **WHEN** запрос без `agent_id` пришёл от панели `w1:p1` вкладки `w1:t2`
- **THEN** запрос привязан к строке `w1:t2`

### Requirement: Перечень ждущих запросов
Плагин MUST вести перечень ждущих запросов: несколько могут ждать одновременно (параллельные вызовы, субагент вместе с главной сессией). Ключ сопоставления — сессия, `agent_id` (если есть), инструмент и равный по значению `tool_input` (у `ExitPlanMode` — без поля `plan`). Узел MUST показывать число своих ждущих запросов, строка агента — и запросов его субагентов. Запрос в состоянии «решение отправлено», чей хук закрыл соединение, MUST NOT считаться ждущим.

#### Scenario: Два параллельных вызова
- **WHEN** сессия присылает два запроса `Read` с разными `file_path`
- **THEN** строка вкладки показывает два запроса, у каждого свой ключ

#### Scenario: Субагент и главная сессия
- **WHEN** ждут запрос субагента и запрос главной сессии той же панели
- **THEN** узел субагента показывает один, строка вкладки — два

#### Scenario: Решение отправлено, хук завершился
- **WHEN** решение по запросу отправлено, хук закрыл соединение, подтверждения в транскрипте ещё нет
- **THEN** узел не считает запрос ждущим, выбор запроса его не предлагает, буфер показывает «решение отправлено»
