## ADDED Requirements

### Requirement: Вкладка и workspace — терминал агента вкладки
Подключение к вкладке MUST открывать вид наблюдения (требование «Панель — наблюдение за терминалом») за панелью агента вкладки (`agent-tree`, «Агент вкладки»), во вкладке без агента — за панелью в фокусе, без неё — за первой по номеру. Подключение к workspace MUST открывать то же для его вкладки `active_tab_id`. Вид MUST быть одним буфером; раскладка окон Neovim MUST NOT меняться.

#### Scenario: Вкладка с агентом и Neovim
- **WHEN** пользователь подключается к вкладке с панелью агента `w1:p1` и панелью Neovim `w1:p2`
- **THEN** открывается наблюдение за `w1:p1` одним буфером, других окон не появляется

#### Scenario: Вкладка без агента
- **WHEN** пользователь подключается к вкладке с одной панелью `w1:p4` с `bash`
- **THEN** открывается наблюдение за `w1:p4`

#### Scenario: Workspace
- **WHEN** пользователь подключается к workspace с активной вкладкой `w1:t2`
- **THEN** открывается наблюдение за агентом вкладки `w1:t2`

### Requirement: Вызов Bash — вывод
Подключение к вызову Bash MUST показывать его вывод только для чтения. У работающего вызова — файл вывода в каталоге задач с дополнением по мере записи по уведомлениям файловой системы; когда файл удалён (вызов завершился), вид MUST сохранять показанное и сообщать о завершении. У завершённого вызова — вывод из результата вызова (`stdout` и `stderr`), при сохранённом полном выводе — этот файл; пустой вывод MUST сообщаться.

#### Scenario: Работающий вызов
- **WHEN** подключён вид работающего вызова, и команда дописывает файл вывода
- **THEN** новый вывод появляется в виде без действий пользователя

#### Scenario: Вызов завершился при открытом виде
- **WHEN** файл вывода работающего вызова удалён
- **THEN** вид сохраняет показанный вывод и сообщает, что вызов завершён

#### Scenario: Завершённый вызов с большим выводом
- **WHEN** у завершённого вызова в результате есть путь сохранённого полного вывода
- **THEN** вид показывает полный вывод из этого файла

## MODIFIED Requirements

### Requirement: Фоновая команда — файл вывода
Подключение к фоновой команде MUST показывать её файл вывода только для чтения, с дополнением по мере записи по уведомлениям файловой системы. Узел команды без файла вывода в дереве не показывается (`agent-tree`, «Узел команды с выводом»); если файл исчез после того, как узел показан или вид открыт, вид MUST сообщать об этом и показывать статус и код выхода из транскрипта.

#### Scenario: Команда ещё работает
- **WHEN** подключён вид работающей команды, и она дописывает файл вывода
- **THEN** новый вывод появляется в виде без действий пользователя

#### Scenario: Файла вывода нет
- **WHEN** вид команды открыт, а файл вывода удалён
- **THEN** вид сообщает, что вывод недоступен, и показывает статус и код выхода

### Requirement: Вид — обычный буфер в окне, из которого открыто дерево
Вид узла (наблюдение, подключение с вводом, история панели, транскрипт, вывод команды, вывод вызова Bash) MUST открываться обычным буфером в окне, из которого открыто дерево; нет такого окна — в предыдущем обычном окне, затем в любом другом, иначе в новом окне рядом с деревом. Окно дерева MUST оставаться на месте, плавающее окно для вида MUST NOT открываться. Уход из буфера вида MUST NOT закрывать вид, `<C-o>` MUST возвращать в него.

#### Scenario: Вид по Enter в окне, из которого открыто дерево
- **WHEN** дерево открыто из окна A, пользователь нажимает Enter на панели в дереве
- **THEN** вид панели показан обычным буфером в окне A, окно дерева на месте и не изменилось, плавающих окон нет, курсор в виде

#### Scenario: Окна, из которого открыто дерево, больше нет
- **WHEN** окно A закрыто, на вкладке есть другое обычное окно B, а пользователь нажимает Enter на узле
- **THEN** вид показан в предыдущем обычном окне, а при его отсутствии — в любом другом обычном окне вкладки

#### Scenario: Других окон нет
- **WHEN** на вкладке открыто только окно дерева
- **THEN** вид показан в новом окне рядом с деревом

#### Scenario: Возврат в вид
- **WHEN** пользователь ушёл из буфера вида (например, открыл файл по ссылке) и нажал `<C-o>`
- **THEN** вид показан снова, наблюдение за узлом не прерывалось
