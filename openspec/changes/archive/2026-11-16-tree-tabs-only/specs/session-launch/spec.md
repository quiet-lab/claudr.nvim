## MODIFIED Requirements

### Requirement: Новая сессия делением панели
Пользователь MUST иметь возможность запустить дополнительную сессию в выбранной вкладке делением панели: плагин MUST разделить панель, выбранную пользователем, методом `pane.split` и запустить агента вида `claude` в новой панели. Панель выбирается так: на строке панели с командой или прочего агента — эта панель; на строке вкладки — из перечня панелей вкладки через `vim.ui.select`, а при одной панели — она без вопроса.

#### Scenario: Запуск делением
- **WHEN** пользователь выбирает панель, направление деления и запускает сессию
- **THEN** сервер получает `pane.split` для этой панели, затем `agent.start` с видом `claude` для созданной панели

#### Scenario: Деление со строки вкладки
- **WHEN** пользователь запускает деление на строке вкладки с панелями `w1:p1` и `w1:p2`
- **THEN** плагин предлагает выбрать одну из них через `vim.ui.select` и делит выбранную

### Requirement: Новая сессия в дереве
Запущенная сессия MUST появляться в дереве по событиям herdr (`pane_created`, `pane_agent_detected`), без специальной обработки результата запуска: строкой новой вкладки или состоянием строки вкладки, в которой разделена панель.

#### Scenario: Появление узла
- **WHEN** после `tab.create` и `agent.start` приходят `pane_created` и `pane_agent_detected`
- **THEN** дерево содержит строку новой вкладки с состоянием агента, строки панели с агентом нет
