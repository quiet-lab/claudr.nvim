## ADDED Requirements

### Requirement: Перечень сессий проекта инстанса
Для выбранной панели с агентом Claude Code плагин MUST показывать перечень сессий проекта этой панели: каталог проекта определяется расположением транскрипта сессии панели, сессиями считаются файлы `<идентификатор>.jsonl` в нём. Строка перечня MUST содержать идентификатор сессии, время последней записи и начало первой реплики пользователя; сессия, которой соответствует живая панель herdr, MUST быть отмечена.

#### Scenario: Проект с несколькими сессиями
- **WHEN** в каталоге проекта панели три файла транскриптов
- **THEN** перечень содержит три строки с идентификатором, временем последней записи и началом первой реплики

#### Scenario: Сессия с живой панелью
- **WHEN** идентификатор сессии совпадает с `agent_session.value` одной из панелей
- **THEN** строка отмечена как работающая

### Requirement: Темы вопросов по коду — отдельный перечень
Сессии, являющиеся темами вопросов по коду (`code-questions`), MUST NOT входить в перечень сессий проекта инстанса: они показываются только в перечне тем.

#### Scenario: Проект с темой
- **WHEN** в каталоге проекта лежит транскрипт сессии, записанной в реестре тем
- **THEN** перечень сессий инстанса его не содержит, перечень тем — содержит

### Requirement: Срок хранения транскриптов
Срок хранения транскриптов задаёт настройка Claude Code (по умолчанию 30 дней); плагин срок MUST NOT менять и MUST NOT хранить копии транскриптов. Перечень MUST показывать только те сессии, транскрипты которых существуют.

#### Scenario: Старый транскрипт удалён Claude Code
- **WHEN** транскрипт сессии удалён очисткой Claude Code
- **THEN** перечень сессий проекта не содержит эту сессию

### Requirement: Просмотр диалога
Выбор сессии из перечня MUST открывать её диалог — реплики пользователя и агента в порядке записи — только для чтения. Реплики MUST поступать от модуля `claude-code-data`. Недоступность транскрипта MUST сообщаться пользователю.

#### Scenario: Просмотр завершённой сессии
- **WHEN** пользователь выбирает сессию из перечня
- **THEN** открывается диалог с репликами пользователя и агента, правка текста невозможна

#### Scenario: Транскрипт удалён
- **WHEN** файл транскрипта исчез после построения перечня
- **THEN** плагин сообщает, что транскрипт недоступен

### Requirement: Источник — файлы Claude Code
Перечень и диалог MUST строиться по файлам Claude Code, без запросов к серверу herdr, кроме определения панелей для отметки работающих сессий.

#### Scenario: Сервера нет
- **WHEN** сервера herdr нет, а каталог проекта известен
- **THEN** перечень и диалоги доступны, отметки работающих сессий отсутствуют
