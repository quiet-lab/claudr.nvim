## ADDED Requirements

### Requirement: Подключение к любому узлу
К любому узлу дерева MUST быть возможно подключиться и увидеть вывод узла в данный момент. Вид определяется видом узла и описан в требованиях ниже.

#### Scenario: Выбор узла
- **WHEN** пользователь выбирает узел дерева и вызывает подключение
- **THEN** открывается вид, соответствующий виду узла

### Requirement: Панель — наблюдение за терминалом
Подключение к панели (с агентом и с командой одинаково) MUST по умолчанию открывать вид наблюдения: экран терминала панели из потока кадров терминала, который сервер отдаёт для наблюдения; первый кадр полный, следующие — приращения. Вид MUST быть только для чтения, MUST NOT мешать работе панели и другим подключённым клиентам. Закрытие вида MUST завершать наблюдение; панель остаётся живой.

#### Scenario: Наблюдение за панелью с агентом
- **WHEN** пользователь подключается к панели с агентом Claude Code
- **THEN** вид показывает экран агента: сначала полный кадр, затем приращения, ввода в панель нет

#### Scenario: Наблюдение за панелью с командой
- **WHEN** пользователь подключается к панели, где нет агента, и в ней появляется новый вывод
- **THEN** вид показывает его по очередному кадру тем же способом, что и для панели с агентом

#### Scenario: Закрытие вида
- **WHEN** пользователь закрывает вид наблюдения
- **THEN** наблюдение завершается, панель продолжает работать

### Requirement: Панель — ввод отдельной командой
Подключение с вводом MUST выполняться отдельной явной командой, не подключением по умолчанию: в буфере терминала Neovim (нужен псевдотерминал) открывается прямое подключение к терминалу панели, ввод пользователя уходит в панель. Подключение с вводом MUST быть возможно для любой панели с терминалом, в том числе без агента; команда подключения «к агенту» MUST NOT использоваться, так как для панели без агента она отказывает.

#### Scenario: Ввод в панель с командой
- **WHEN** пользователь вызывает подключение с вводом к панели без агента
- **THEN** открывается буфер терминала с экраном панели, набранный текст попадает в панель

#### Scenario: Отключение
- **WHEN** пользователь отключается от панели, подключённой с вводом
- **THEN** панель и её процессы остаются живыми

### Requirement: Занятый терминал
Если к терминалу панели уже подключён другой клиент с вводом, сервер отказывает второму подключению без вытеснения. Плагин MUST показать причину отказа и предложить вытеснение явным действием пользователя; сам плагин MUST NOT вытеснять другого клиента.

#### Scenario: Второй клиент с вводом
- **WHEN** пользователь подключается с вводом к терминалу, который занят другим клиентом
- **THEN** плагин показывает отказ сервера и предлагает вытеснение, подключения с вытеснением без решения пользователя нет

#### Scenario: Вытеснение по решению пользователя
- **WHEN** пользователь подтверждает вытеснение
- **THEN** плагин подключается с вытеснением, прежний клиент отключается сервером

### Requirement: Панель — прокрутка истории
Для просмотра истории панели вид MUST давать чтение через `pane.read` в пределах, которые даёт сервер: строки, ушедшие с экрана, доступны, пока их держит сервер; для полноэкранной программы доступен только текущий экран. Чтение MUST выполняться по запросу пользователя, не по событиям панели.

#### Scenario: История оболочки
- **WHEN** пользователь запрашивает историю панели с оболочкой
- **THEN** вид показывает последние строки панели в пределах, которые отдаёт сервер, только для чтения

#### Scenario: Полноэкранная программа
- **WHEN** пользователь запрашивает историю панели с полноэкранной программой
- **THEN** вид показывает текущий экран программы и сообщает, что истории нет

### Requirement: Субагент — транскрипт по мере записи
Подключение к субагенту MUST показывать его транскрипт только для чтения, с дополнением по мере записи по уведомлениям `claude-code-data`. Реплики MUST показываться как реплики диалога, а не сырые строки JSON.

#### Scenario: Работающий субагент
- **WHEN** подключён вид работающего субагента и в транскрипт дописывается реплика
- **THEN** реплика появляется в виде без действий пользователя

#### Scenario: Завершённый субагент
- **WHEN** подключён вид завершённого субагента
- **THEN** показан весь транскрипт, новых дополнений нет

### Requirement: Фоновая команда — файл вывода
Подключение к фоновой команде MUST показывать её файл вывода только для чтения, с дополнением по мере записи по уведомлениям файловой системы. Если файла вывода нет, вид MUST сообщать об этом и показывать статус и код выхода из транскрипта.

#### Scenario: Команда ещё работает
- **WHEN** подключён вид работающей команды, и она дописывает файл вывода
- **THEN** новый вывод появляется в виде без действий пользователя

#### Scenario: Файла вывода нет
- **WHEN** команда завершена, а файла вывода нет
- **THEN** вид сообщает, что вывод недоступен, и показывает статус и код выхода

### Requirement: Контейнеры — перечень панелей
Подключение к workspace или вкладке MUST показывать перечень их панелей с подписями и состояниями; выбор панели из перечня MUST открывать вид этой панели. Автоматического выбора первой панели MUST NOT быть.

#### Scenario: Вкладка с двумя панелями
- **WHEN** пользователь подключается к вкладке, в которой панель с агентом и панель с командой
- **THEN** открывается перечень из двух панелей с состояниями, выбор строки открывает вид соответствующей панели

#### Scenario: Состояние в перечне меняется
- **WHEN** у панели из открытого перечня приходит `pane.agent_status_changed`
- **THEN** строка перечня показывает новое состояние

### Requirement: Отсутствие таймеров и опроса в видах
Обновление видов MUST идти по событиям (кадры наблюдения, уведомления файловой системы); таймеры и опрос MUST NOT использоваться.

#### Scenario: Тишина в панели
- **WHEN** панель не меняет вывод
- **THEN** плагин не вызывает `pane.read` и не получает новых кадров
