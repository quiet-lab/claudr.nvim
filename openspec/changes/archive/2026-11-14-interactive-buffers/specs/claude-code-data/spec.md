## MODIFIED Requirements

### Requirement: Единый модуль чтения данных Claude Code
Все данные Claude Code (транскрипты, `meta.json` субагентов, записи фоновых команд, файлы вывода) MUST читаться одним модулем. Остальной код MUST получать от него записи видов «субагент», «фоновая команда» и «реплика диалога» и MUST NOT разбирать эти форматы сам. Модуль дополнительно MUST разбирать вход хука `PermissionRequest` и вложение `hook_permission_decision` транскрипта (`agent-dialogs`).

#### Scenario: Изменение формата
- **WHEN** Claude Code меняет запись транскрипта
- **THEN** правка ограничивается модулем чтения, а дерево, виды и перечни получают те же виды записей

#### Scenario: Вход хука и вложение решения
- **WHEN** приходит вход хука `PermissionRequest` или в транскрипте появляется вложение `hook_permission_decision`
- **THEN** их разбирает модуль чтения, остальной код этих форматов не разбирает
