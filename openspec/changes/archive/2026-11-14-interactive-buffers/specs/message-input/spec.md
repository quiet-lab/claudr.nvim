## ADDED Requirements

### Requirement: Окно ввода сообщения
Отдельная клавиша MUST открывать всплывающее окно ввода сообщения для агента той сессии, чей вид панели показан (или чей узел выбран в дереве). Буфер окна MUST быть обычным буфером Neovim с привычным редактированием. Субагентам и фоновым командам окно MUST NOT открываться: действует запрет `messaging`.

#### Scenario: Вызов из вида панели
- **WHEN** пользователь нажимает клавишу ввода в виде панели с агентом
- **THEN** открывается плавающее окно с пустым редактируемым буфером, целью отправки назначена панель этого вида

#### Scenario: Вызов на узле субагента
- **WHEN** пользователь вызывает окно ввода на узле субагента
- **THEN** окно не открывается, плагин сообщает, что субагенту писать нельзя

### Requirement: Отправка сообщения
Сообщение MUST отправляться сохранением буфера (`:w`), Shift+Enter или Shift+Space, одним вызовом `agent.prompt` с полным текстом. При успехе окно MUST закрываться, черновик MUST очищаться. Пустой текст MUST NOT отправляться. Клавиши отправки MUST переназначаться настройкой.

#### Scenario: Отправка сохранением
- **WHEN** в окне набран текст и выполнено `:w`
- **THEN** сервер получает один `agent.prompt` с целью этой панели и набранным текстом, окно закрыто

#### Scenario: Пустое сообщение
- **WHEN** буфер пуст или состоит из пробелов и пользователь отправляет
- **THEN** вызова `agent.prompt` нет, окно остаётся

### Requirement: Многострочный текст
Многострочный текст MUST уходить одним вызовом `agent.prompt` без изменений: переводы строк, пустые строки, отступы, кавычки и кириллица сохраняются; плагин MUST NOT разбивать текст на части.

#### Scenario: Несколько строк
- **WHEN** отправляется текст из трёх строк, средняя пуста
- **THEN** сервер получает один `agent.prompt`, текст совпадает с набранным байт в байт

### Requirement: Черновик
Закрытие окна без отправки MUST сохранять набранный текст до следующего открытия окна для той же сессии; черновики разных сессий MUST храниться раздельно. После успешной отправки черновик MUST очищаться. Черновик живёт в памяти Neovim, между запусками не сохраняется.

#### Scenario: Закрытие без отправки
- **WHEN** пользователь набрал текст, закрыл окно, затем снова открыл окно для той же сессии
- **THEN** буфер содержит прежний текст

#### Scenario: Другая сессия
- **WHEN** окно открывается для другой сессии
- **THEN** буфер содержит черновик этой сессии, а не прежней

### Requirement: Ошибка отправки
При отказе сервера или его недоступности окно MUST оставаться открытым с набранным текстом, причина MUST показываться пользователю.

#### Scenario: Сервер недоступен
- **WHEN** отправка не удалась из-за недоступности сервера
- **THEN** плагин показывает причину, окно и текст на месте, ничего не отложено

### Requirement: Работающий агент — очередь
Агенту в состоянии `working` сервер принимает сообщение в очередь. После принятия плагин MUST сообщить пользователю, что сообщение встанет в очередь агента.

#### Scenario: Сообщение работающему агенту
- **WHEN** состояние агента `working`, сервер отвечает на `agent.prompt` успехом
- **THEN** окно закрыто, пользователь видит сообщение, что текст поставлен в очередь агента

### Requirement: Заблокированный агент — диалог
Если сервер отвечает на `agent.prompt` ошибкой `agent_blocked`, текст MUST остаться черновиком, а плагин MUST открыть буфер диалога агента (`agent-dialogs`), если для сессии есть ждущий запрос; иначе — сообщить, что агент ждёт ответа, и предложить подключение с вводом через терминал. Текст MUST NOT уходить иным способом.

#### Scenario: Запрос есть
- **WHEN** сервер отвечает `agent_blocked`, и для сессии есть ждущий запрос
- **THEN** открывается буфер диалога, набранный текст сохранён как черновик

#### Scenario: Запроса нет
- **WHEN** сервер отвечает `agent_blocked`, ждущего запроса нет
- **THEN** плагин сообщает, что агент ждёт ответа, и предлагает подключение с вводом; текст в панель не попадает

### Requirement: Начало с «/» или «!»
Текст, начинающийся с `/` или `!`, Claude Code понимает как команду или режим оболочки. По умолчанию плагин MUST отправлять текст как есть и перед отправкой сообщать об этом. Настройка защиты MUST добавлять к такому тексту ведущий пробел.

#### Scenario: По умолчанию
- **WHEN** отправляется текст `/clear`
- **THEN** плагин сообщает, что Claude Code поймёт текст как команду, и отправляет `/clear` без изменений

#### Scenario: Защита включена
- **WHEN** защита включена, отправляется текст `/clear`
- **THEN** сервер получает текст ` /clear` с ведущим пробелом
