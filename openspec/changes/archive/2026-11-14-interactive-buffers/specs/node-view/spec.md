## MODIFIED Requirements

### Requirement: Панель — ввод отдельной командой
Подключение с вводом MUST выполняться отдельной явной командой, не подключением по умолчанию: в буфере терминала Neovim (нужен псевдотерминал) открывается прямое подключение к терминалу панели, ввод пользователя уходит в панель. Подключение с вводом MUST быть возможно для любой панели с терминалом, в том числе без агента; команда подключения «к агенту» MUST NOT использоваться, так как для панели без агента она отказывает. Эта команда остаётся запасным путём для сессий без хука и для диалогов вне хука (`agent-dialogs`).

#### Scenario: Ввод в панель с командой
- **WHEN** пользователь вызывает подключение с вводом к панели без агента
- **THEN** открывается буфер терминала с экраном панели, набранный текст попадает в панель

#### Scenario: Отключение
- **WHEN** пользователь отключается от панели, подключённой с вводом
- **THEN** панель и её процессы остаются живыми
