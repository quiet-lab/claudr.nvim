## MODIFIED Requirements

### Requirement: Вид — обычный буфер в окне, из которого открыто дерево
Вид узла (наблюдение, подключение с вводом, история панели, транскрипт, вывод команды, вывод вызова Bash) MUST открываться обычным буфером в окне, из которого открыто дерево; нет такого окна — в предыдущем обычном окне, затем в любом другом, иначе в новом окне рядом с деревом. Окно дерева MUST оставаться на месте, плавающее окно для вида MUST NOT открываться. Уход из буфера вида MUST NOT закрывать вид, `<C-o>` MUST возвращать в него; исключение — замена вида другим видом (требование «Замена вида в окне»).

#### Scenario: Вид по Enter в окне, из которого открыто дерево
- **WHEN** дерево открыто из окна A, пользователь нажимает Enter на панели в дереве
- **THEN** вид панели показан обычным буфером в окне A, окно дерева на месте и не изменилось, плавающих окон нет, курсор в виде

#### Scenario: Окна, из которого открыто дерево, больше нет
- **WHEN** окно A закрыто, на вкладке есть другое обычное окно B, а пользователь нажимает Enter на узле
- **THEN** вид показан в предыдущем обычном окне, а при его отсутствии — в любом другом обычном окне вкладки

#### Scenario: Других окон нет
- **WHEN** на вкладке открыто только окно дерева
- **THEN** вид показан в новом окне рядом с деревом

#### Scenario: Возврат в вид
- **WHEN** пользователь ушёл из буфера вида (например, открыл файл по ссылке) и нажал `<C-o>`
- **THEN** вид показан снова, наблюдение за узлом не прерывалось

## ADDED Requirements

### Requirement: Замена вида в окне
Вид, открытый в окне, MUST закрывать прежний вид этого окна так же, как `q` (процесс наблюдения завершается, наблюдение за файлами снимается), если буфер прежнего вида больше нигде не показан; окно остаётся. Подключение с вводом заменой MUST NOT закрываться. Enter на узле, вид которого уже открыт, MUST показывать этот вид в окне, а не открывать второй. Вид, скрытый уходом в файл, MUST оставаться открытым до `q`, закрытия окна или выхода из Neovim.

#### Scenario: Enter на другом узле
- **WHEN** в окне A показано наблюдение за `w1:p2`, пользователь нажимает Enter на `w1:p1` в дереве
- **THEN** окно A показывает наблюдение за `w1:p1`, буфер прежнего вида удалён, его процесс наблюдения завершён

#### Scenario: Повторный Enter на узле с открытым видом
- **WHEN** наблюдение за `w1:p1` открыто, пользователь нажимает Enter на `w1:p1` или на вкладке, агент которой — `w1:p1`
- **THEN** окно показывает тот же вид, второго вида и второго процесса наблюдения нет

#### Scenario: Подключение с вводом
- **WHEN** в окне A подключение с вводом к `w1:p2`, пользователь нажимает Enter на `w1:p1`
- **THEN** окно A показывает наблюдение за `w1:p1`, подключение с вводом остаётся открытым и не обрывается
