## MODIFIED Requirements

### Requirement: Открытие файла
Клавиша открытия (по умолчанию `gd`) на ссылке MUST открывать файл в том же окне, из которого сделан переход, на указанных строке и столбце (без них — с начала файла), обычным открытием файла с записью в список переходов, чтобы `<C-o>` возвращал в буфер плагина; буфер плагина MUST оставаться живым. Если окно плавающее, файл MUST открываться в окне редактирования (окно с обычным буфером), а если его нет — в новом окне.

#### Scenario: Открытие на строке и столбце
- **WHEN** пользователь нажимает `gd` на ссылке `lua/foo.lua:42:7` в виде панели
- **THEN** файл открыт в том же окне, курсор на строке 42, столбце 7, вид панели остаётся живым

#### Scenario: Возврат в буфер плагина
- **WHEN** после `gd` пользователь нажимает `<C-o>`
- **THEN** в окне снова буфер плагина с прежним положением курсора

#### Scenario: Переход из плавающего окна
- **WHEN** пользователь нажимает `gd` на ссылке в плавающем окне плагина
- **THEN** файл открывается в окне редактирования, без него — в новом окне

#### Scenario: Нет окна редактирования
- **WHEN** пользователь нажимает `gd` на ссылке в плавающем окне плагина, а все обычные окна вкладки заняты буферами плагина или их нет
- **THEN** файл открывается в новом окне
