## ADDED Requirements

### Requirement: Вид — обычный буфер в окне, из которого открыто дерево
Вид узла (наблюдение, подключение с вводом, история панели, транскрипт, вывод команды, перечень панелей) MUST открываться обычным буфером в окне, из которого открыто дерево; нет такого окна — в предыдущем обычном окне, затем в любом другом, иначе в новом окне рядом с деревом. Окно дерева MUST оставаться на месте, плавающее окно для вида MUST NOT открываться. Уход из буфера вида MUST NOT закрывать вид, `<C-o>` MUST возвращать в него.

#### Scenario: Вид по Enter в окне, из которого открыто дерево
- **WHEN** дерево открыто из окна A, пользователь нажимает Enter на панели в дереве
- **THEN** вид панели показан обычным буфером в окне A, окно дерева на месте и не изменилось, плавающих окон нет, курсор в виде

#### Scenario: Окна, из которого открыто дерево, больше нет
- **WHEN** окно A закрыто, на вкладке есть другое обычное окно B, а пользователь нажимает Enter на узле
- **THEN** вид показан в предыдущем обычном окне, а при его отсутствии — в любом другом обычном окне вкладки

#### Scenario: Других окон нет
- **WHEN** на вкладке открыто только окно дерева
- **THEN** вид показан в новом окне рядом с деревом

#### Scenario: Возврат в вид
- **WHEN** пользователь ушёл из буфера вида (например, открыл файл по ссылке) и нажал `<C-o>`
- **THEN** вид показан снова, наблюдение за узлом не прерывалось

### Requirement: Закрытие вида оставляет окно
Клавиша `q` в виде MUST удалять буфер вида и освобождать вид (процесс наблюдения завершается, подписки снимаются), а окно MUST оставаться на месте с прежним буфером окна, иначе с пустым. Закрытие окна, в котором показан вид, MUST закрывать вид, если буфер нигде не показан.

#### Scenario: Закрытие клавишей
- **WHEN** в окне A, где раньше был файл, открыт вид и пользователь нажимает `q`
- **THEN** окно A показывает прежний файл, раскладка окон не изменилась, процесс наблюдения завершён

#### Scenario: Единственное окно
- **WHEN** вид показан в единственном обычном окне вкладки и пользователь нажимает `q`
- **THEN** окно остаётся, показывает прежний или пустой буфер

#### Scenario: Закрытие окна
- **WHEN** окно с видом закрыто командой редактора
- **THEN** буфер вида удалён, процесс наблюдения завершён
