## MODIFIED Requirements

### Requirement: Завершённые узлы
Завершённые субагенты и фоновые команды MUST оставаться в модели дерева с состоянием «завершён» до закрытия панели владельца, но в окне дерева MUST быть скрыты по умолчанию. Показ завершённых узлов MUST переключаться командой; состояние переключателя — настройка `show_finished` со значением по умолчанию «скрывать».

#### Scenario: Завершённый узел остаётся
- **WHEN** субагент завершён, а панель владельца жива
- **THEN** узел остаётся в модели с состоянием «завершён», даже когда в окне дерева он не показан

#### Scenario: Скрыты по умолчанию
- **WHEN** плагин настроен без `show_finished`
- **THEN** завершённый субагент и завершённая команда в окне дерева не показываются

#### Scenario: Показ по команде
- **WHEN** пользователь переключает показ завершённых узлов при настройке по умолчанию
- **THEN** завершённые субагенты и команды появляются в дереве

#### Scenario: Скрытие завершённых
- **WHEN** показ включён, у панели есть работающий субагент и оборванная команда, и пользователь переключает показ
- **THEN** завершённые субагенты и команды скрываются, работающий и оборванный остаются

#### Scenario: Закрытие панели владельца
- **WHEN** панель владельца закрыта
- **THEN** узлы субагентов и команд этой панели исчезают из модели вместе с ней

### Requirement: Обновление по событиям
Дерево MUST обновляться по событиям: структура и состояния панелей — по событиям herdr, субагенты и фоновые команды — по уведомлениям модуля `claude-code-data`. Дерево MUST NOT использовать таймеры и периодическое чтение, кроме таймера кадров анимации («Анимация состояний»), который MUST NOT читать сокет и файлы.

#### Scenario: Новый субагент
- **WHEN** сессия запускает субагента и модуль сообщает о нём
- **THEN** узел субагента появляется в дереве без действий пользователя

#### Scenario: Ничего не происходит
- **WHEN** событий herdr и файловой системы нет, а анимируемых узлов на экране нет
- **THEN** плагин не читает ни сокет, ни файлы Claude Code, и ни один таймер не заведён

#### Scenario: Таймер кадров не читает данные
- **WHEN** таймер кадров срабатывает
- **THEN** плагин не обращается к сокету herdr и к файлам Claude Code, модель дерева не меняется

## ADDED Requirements

### Requirement: Значки узлов
Каждый узел в окне дерева MUST начинаться значком: workspace, вкладка и панель с агентом — значком состояния `agent_status`; панель с командой — знаком `$`; субагент и фоновая команда — значком состояния и знаком вида (`🤖` для субагента, `🔧` для команды). Значок, источника которого нет, MUST опускаться без ошибки.

#### Scenario: Панель с агентом
- **WHEN** в снимке у панели `agent = "claude"` и `agent_status = "idle"`
- **THEN** строка узла начинается значком состояния `idle`, а буквенного обозначения вида нет

#### Scenario: Субагент и команда
- **WHEN** у панели есть работающий субагент и завершённая команда, показ завершённых включён
- **THEN** строка субагента содержит значок `working` и знак `🤖`, строка команды — значок `done` и знак `🔧`

#### Scenario: Состояния нет
- **WHEN** у вкладки в снимке нет поля `agent_status`
- **THEN** строка вкладки показывается без значка состояния

### Requirement: Подписи workspace и вкладок
Подпись workspace MUST состоять из символа токена `tokens.symbol` и `label` через пробел; без токена или при `label`, уже начинающемся с символа, — из `label`. Подпись вкладки MUST быть её `label`. Подписи workspace, его вкладок и панелей с агентом MUST быть окрашены цветом токена `tokens.color` workspace; пустой или не цвет `#RGB`/`#RRGGBB` MUST быть пропущен.

#### Scenario: Символ и цвет
- **WHEN** у workspace `label = "demo"`, `tokens = {symbol = "S1", color = "#336699"}`
- **THEN** подпись — `S1 demo`, она и подписи его вкладок и панелей с агентом окрашены `#336699`

#### Scenario: Токенов нет
- **WHEN** у workspace в снимке нет `tokens`
- **THEN** подпись — `label`, цвет подписи обычный

#### Scenario: Не цвет
- **WHEN** `tokens.color = "red"`
- **THEN** подписи показываются обычным цветом, ошибки нет

### Requirement: Значки состояний
Значок состояния MUST браться из таблицы значков herdr («Значки состояний из конфигурации herdr»): `idle`, `working`, `blocked`, `done`, `unknown`. Состояние субагента и команды MUST отображаться так: «работает» — как `working`, «завершён» — как `done`, «оборван» — как `unknown`. Неизвестное значение `agent_status` MUST показываться значком `unknown` и значением в подписи.

#### Scenario: Значки по таблице
- **WHEN** в таблице `working` — кадры `a`, `b`, `blocked` — `x`, а панели в состояниях `working` и `blocked`
- **THEN** строки начинаются кадром `a` (или `b`) и значком `x`

#### Scenario: Состояние done
- **WHEN** приходит `pane.agent_status_changed` с `agent_status = done`
- **THEN** узел показывает значок `done`

#### Scenario: Состояние субагента
- **WHEN** субагент «оборван»
- **THEN** его строка начинается значком `unknown`

#### Scenario: Неизвестное значение
- **WHEN** сервер присылает состояние `paused`
- **THEN** узел показывает значок `unknown` и `paused` в подписи

### Requirement: Анимация состояний
Таймер кадров MUST быть заведён, пока одновременно выполнено: буфер дерева показан в окне текущей вкладки Neovim, и среди показанных узлов (не свёрнутых и не скрытых) есть узел со значком из нескольких кадров. Иначе таймер MUST быть остановлен. Срабатывание MUST перепроверять эти условия.

#### Scenario: Таймер заведён
- **WHEN** дерево показано, а у показанной панели состояние `working` с несколькими кадрами
- **THEN** таймер кадров заведён

#### Scenario: Нет анимируемых узлов
- **WHEN** показаны только узлы в состояниях с одним кадром
- **THEN** таймер не заведён

#### Scenario: Окно закрыто
- **WHEN** окно дерева закрыто или в текущей вкладке дерева нет
- **THEN** таймер остановлен, и заводится заново при показе дерева с анимируемым узлом

#### Scenario: Анимируемый узел скрыт
- **WHEN** единственный узел в состоянии `working` свёрнут вместе с родителем
- **THEN** таймер остановлен, а разворачивание заводит его снова

#### Scenario: Состояние изменилось
- **WHEN** событие переводит последний `working` в `idle`, затем другое — `idle` в `working`
- **THEN** после первого таймер остановлен, после второго заведён

### Requirement: Кадр анимации
Кадр значка MUST быть функцией монотонных часов и периода состояния: номер кадра равен целой части от времени, делённого на период, по модулю числа кадров. Смена кадра MUST перерисовывать только значки анимируемых узлов (метка extmark), не меняя текст буфера, модель и положение курсора.

#### Scenario: Смена кадра
- **WHEN** срабатывание вызвано напрямую с временем, больше прежнего на один период
- **THEN** у каждой строки `working` показан следующий кадр, по кругу после последнего

#### Scenario: Кадр по часам
- **WHEN** срабатывание вызвано со временем, равным пяти периодам, а кадров три
- **THEN** показан кадр с номером 2 (счёт с нуля)

#### Scenario: Только значки
- **WHEN** срабатывание сменило кадр
- **THEN** строки буфера, список узлов и положение курсора прежние, изменены только метки значков анимируемых строк

### Requirement: Режим без значков
Настройка `icons` MUST принимать `"herdr"` (по умолчанию) и `"text"`. При `"text"` узлы MUST показываться прежними буквенными обозначениями (`W`, `T`, `A`, `$`, `S`, `&`) с состоянием словом в квадратных скобках, значки и цвет workspace MUST NOT показываться, таймер кадров MUST NOT заводиться.

#### Scenario: Текстовый режим
- **WHEN** настроено `icons = "text"` и у панели `agent_status = working`
- **THEN** строка панели начинается `A`, содержит `[working]`, значка и таймера нет

#### Scenario: Режим по умолчанию
- **WHEN** `icons` не задана
- **THEN** узлы показываются значками herdr
