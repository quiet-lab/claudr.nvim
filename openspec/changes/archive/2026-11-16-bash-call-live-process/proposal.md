## Why

В каталоге задач сессии остаются файлы вывода прерванных вызовов Bash: записи с
идентификатором задачи в транскрипте нет, процесса нет, а файл не удаляется. По прежнему
правилу такой файл считается работающим вызовом, и дерево показывает строки «🐚 Bash» без
команды до перезапуска Neovim. Пользователь выбрал правило: работающим вызовом считается
только файл, в который пишет живой процесс.

## What Changes

- Работающий вызов Bash — обычный файл `.output` каталога задач, не принадлежащий фоновой
  команде, у которого найден живой процесс оболочки вызова; без процесса узла нет.
- Процесс вызова запоминается; при каждом пересчёте состояния сессии (по событию каталога
  задач или транскриптов) проверяется, что он жив и пишет в тот же файл; иначе запись
  работающего вызова снимается.
- Подпись работающего вызова — команда процесса; подпись `Bash` без команды не нужна.
