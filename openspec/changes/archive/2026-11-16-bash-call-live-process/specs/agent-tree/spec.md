## MODIFIED Requirements

### Requirement: Подпись и смена вида вызова Bash
Подпись работающего вызова Bash MUST быть его командой; завершённого — `description`, без него — `command`. Вызов, переведённый в фон, MUST становиться фоновой командой с тем же узлом. Узел работающего вызова MUST исчезать вместе с записью работающего вызова (`claude-code-data`, «Завершение процесса вызова»); открытый вид его вывода MUST сохранять показанное.

#### Scenario: Подпись работающего вызова
- **WHEN** работает вызов Bash с командой `make all`
- **THEN** подпись узла — `make all`

#### Scenario: Подпись без команды
- **WHEN** процесс файла вывода в каталоге задач определить нельзя
- **THEN** узла вызова нет, строки `Bash` без команды в дереве нет

#### Scenario: Перевод в фон
- **WHEN** работающий вызов переведён в фон, и в транскрипте появилась фоновая команда с тем же идентификатором задачи
- **THEN** узел остаётся на месте строкой фоновой команды

#### Scenario: Прерванный вызов в дереве
- **WHEN** открыт вид вывода работающего вызова, вызов прерван, процесс завершился, а файл остался
- **THEN** после записи результата в транскрипт узла вызова нет, вид сохраняет показанный вывод
