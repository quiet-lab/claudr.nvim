## MODIFIED Requirements

### Requirement: Работающий вызов Bash
Вызовом Bash MUST считаться вызов инструмента Bash без `run_in_background: true`. Работающим вызовом MUST считаться обычный файл `.output` в каталоге задач сессии, не принадлежащий фоновой команде из записей транскрипта, в который пишет живой процесс оболочки вызова — процесс, чей поток вывода направлен в этот файл; запись содержит идентификатор задачи (имя файла), путь файла и команду из командной строки процесса. Файл без живого процесса MUST NOT давать запись. Вызов принадлежит сессии каталога задач. Удаление файла MUST завершать запись работающего вызова.

#### Scenario: Работающий вызов
- **WHEN** в каталоге задач сессии появляется файл `b1.output`, в него пишет живой процесс оболочки, а фоновой команды `b1` в транскриптах нет
- **THEN** модуль отдаёт работающий вызов Bash `b1` с путём файла и командой

#### Scenario: Процесс не найден
- **WHEN** в каталоге задач лежит файл `b2.output` прерванного вызова, процесса, пишущего в него, нет
- **THEN** записи вызова `b2` нет, ошибки нет

## ADDED Requirements

### Requirement: Завершение процесса вызова
Процесс работающего вызова MUST проверяться при каждом пересчёте состояния сессии, вызванном уведомлением каталога задач или транскриптов; если процесс исчез или его поток вывода больше не направлен в файл, запись работающего вызова MUST сниматься, хотя файл остаётся. Модуль MUST NOT опрашивать процесс по таймеру.

#### Scenario: Прерванный вызов
- **WHEN** процесс работающего вызова `b3` завершился, файл `b3.output` остался, а в транскрипт дописаны вызов и результат с `interrupted`
- **THEN** после чтения дописанного транскрипта записи работающего вызова `b3` нет
