# file-references Specification

## Purpose
Работа с путями к файлам в буферах плагина: предпросмотр файла и открытие на нужной строке и столбце.

## Requirements

### Requirement: Путь под курсором — ссылка
В буферах плагина с содержимым Claude Code (вид наблюдения за панелью, транскрипт субагента, вывод фоновой команды, диалог из истории сессий, окно темы вопросов по коду, буфер диалога агента) путь под курсором MUST считаться ссылкой. Допустимые виды: `файл`, `файл:строка`, `файл:строка:столбец`; путь абсолютный или относительный.

#### Scenario: Ссылка со строкой и столбцом
- **WHEN** курсор стоит на тексте `lua/foo.lua:42:7` в окне темы вопросов по коду
- **THEN** плагин определяет ссылку: файл `lua/foo.lua`, строка 42, столбец 7

#### Scenario: Ссылка без строки
- **WHEN** курсор стоит на абсолютном пути без номера строки
- **THEN** плагин определяет ссылку на этот файл без строки и столбца

### Requirement: Границы ссылки
Окружающие кавычки, обратные апострофы и скобки, а также завершающие знаки `.`, `,`, `;`, `:` MUST NOT входить в путь и номера. Курсор MAY стоять на любом символе ссылки.

#### Scenario: Ссылка в обратных апострофах
- **WHEN** в тексте записано (`lua/foo.lua:42`), а курсор стоит на слове `foo`
- **THEN** ссылка — `lua/foo.lua`, строка 42, без скобок и апострофов

#### Scenario: Знак препинания после ссылки
- **WHEN** после ссылки в тексте стоит точка или запятая
- **THEN** знак не входит в ссылку

### Requirement: Разрешение пути и существование файла
Относительный путь MUST разрешаться от рабочего каталога сессии, которой принадлежит буфер. Путь к несуществующему файлу и путь к каталогу MUST NOT считаться ссылкой.

#### Scenario: Относительный путь
- **WHEN** в буфере панели с рабочим каталогом `/src` стоит ссылка `lua/foo.lua`, а файл `/src/lua/foo.lua` существует
- **THEN** ссылка указывает на `/src/lua/foo.lua`

#### Scenario: Файла нет
- **WHEN** файл по пути под курсором не существует
- **THEN** путь ссылкой не считается

### Requirement: Предпросмотр
Клавиша предпросмотра (по умолчанию `K`) на ссылке MUST открывать плавающее окно с файлом на указанной строке: с подсветкой синтаксиса по типу файла, только для чтения, строка выделена. Фокус MUST оставаться в исходном буфере; столбец в предпросмотре не используется. Строка за концом файла заменяется последней строкой.

#### Scenario: Предпросмотр на строке
- **WHEN** пользователь нажимает `K` на ссылке `lua/foo.lua:42`
- **THEN** открывается плавающее окно с файлом, строка 42 видна и выделена, буфер окна только для чтения, фокус остаётся в буфере со ссылкой

#### Scenario: Строка за концом файла
- **WHEN** в файле 10 строк, а ссылка указывает на строку 42
- **THEN** окно показывает десятую строку

### Requirement: Закрытие предпросмотра
Окно предпросмотра MUST закрываться при движении курсора в исходном буфере, при выходе из него и по Escape. Закрытие MUST идти по событиям редактора, без таймеров.

#### Scenario: Движение курсора
- **WHEN** окно предпросмотра открыто и курсор в исходном буфере сдвинулся
- **THEN** окно закрыто

#### Scenario: Escape
- **WHEN** окно предпросмотра открыто и пользователь нажимает Escape
- **THEN** окно закрыто, фокус остался в исходном буфере

### Requirement: Открытие файла
Клавиша открытия (по умолчанию `gd`) на ссылке MUST открывать файл в окне редактирования на указанных строке и столбце (без них — с начала файла). Буфер плагина MUST оставаться на месте. Окно редактирования — окно с обычным буфером; если его нет, MUST открываться новое.

#### Scenario: Открытие на строке и столбце
- **WHEN** пользователь нажимает `gd` на ссылке `lua/foo.lua:42:7` в виде панели
- **THEN** файл открыт в окне редактирования, курсор на строке 42, столбце 7, вид панели остаётся открытым

#### Scenario: Нет окна редактирования
- **WHEN** все окна вкладки Neovim заняты буферами плагина
- **THEN** файл открывается в новом окне

### Requirement: Вне ссылки — обычное поведение
Если под курсором нет ссылки, `K` и `gd` MUST вести себя как без плагина (действия, назначенные им в буфере до плагина или по умолчанию).

#### Scenario: Слово, не являющееся ссылкой
- **WHEN** пользователь нажимает `K` на слове, которое не путь к существующему файлу
- **THEN** выполняется обычное действие `K`, окно предпросмотра не открывается

### Requirement: Область и настройка клавиш
Клавиши MUST назначаться только в буферах плагина с содержимым Claude Code и MUST переназначаться настройкой (в том числе отключаться). В терминальном буфере подключения с вводом они MUST действовать после выхода из режима ввода терминала.

#### Scenario: Буфер вне плагина
- **WHEN** пользователь нажимает `K` в обычном буфере с кодом
- **THEN** клавиша работает как без плагина

#### Scenario: Переназначение
- **WHEN** в настройке для предпросмотра задана другая клавиша
- **THEN** предпросмотр открывает она, `K` в буферах плагина ведёт себя обычно

#### Scenario: Терминальный буфер
- **WHEN** пользователь вышел из режима ввода терминального буфера и нажал `gd` на ссылке
- **THEN** файл открывается в окне редактирования, терминал остаётся подключённым
