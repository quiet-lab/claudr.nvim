# session-launch Specification

## Purpose
Запуск дополнительной сессии Claude Code в любом workspace и любой вкладке; готовность агента — по событию его состояния.

## Requirements

### Requirement: Выбор workspace и вкладки
Целью запуска MUST быть workspace и вкладка, выбранные пользователем: узлом дерева или из перечня через `vim.ui.select`.

#### Scenario: Выбор из перечня
- **WHEN** пользователь вызывает запуск без выбранного узла
- **THEN** плагин предлагает перечень workspace через `vim.ui.select`

### Requirement: Новая сессия в новой вкладке
Пользователь MUST иметь возможность запустить дополнительную сессию Claude Code в выбранном workspace: плагин MUST создать вкладку (`tab.create`) и запустить агента вида `claude` (`agent.start`) в корневой панели созданной вкладки.

#### Scenario: Запуск в workspace
- **WHEN** пользователь выбирает workspace и запускает сессию в новой вкладке
- **THEN** сервер получает `tab.create` для этого workspace, затем `agent.start` с видом `claude` и панелью `root_pane` из ответа

### Requirement: Новая сессия делением панели
Пользователь MUST иметь возможность запустить дополнительную сессию в выбранной вкладке делением панели: плагин MUST разделить панель, выбранную пользователем, методом `pane.split` и запустить агента вида `claude` в новой панели. Панель выбирается так: на строке панели с командой или прочего агента — эта панель; на строке вкладки — из перечня панелей вкладки через `vim.ui.select`, а при одной панели — она без вопроса.

#### Scenario: Запуск делением
- **WHEN** пользователь выбирает панель, направление деления и запускает сессию
- **THEN** сервер получает `pane.split` для этой панели, затем `agent.start` с видом `claude` для созданной панели

#### Scenario: Деление со строки вкладки
- **WHEN** пользователь запускает деление на строке вкладки с панелями `w1:p1` и `w1:p2`
- **THEN** плагин предлагает выбрать одну из них через `vim.ui.select` и делит выбранную

### Requirement: Рабочий каталог
Плагин MUST NOT передавать рабочий каталог при создании вкладки и деления: действует значение herdr по умолчанию.

#### Scenario: Запуск без каталога
- **WHEN** плагин создаёт вкладку
- **THEN** в запросе `tab.create` нет поля `cwd`

### Requirement: Запуск без блокировки Neovim
Плагин MUST вызывать `agent.start` без `timeout_ms` и MUST NOT ждать готовности агента: после ответа сервера он MUST сообщить, что агент запускается. Готовность MUST определяться по состоянию агента созданной панели в снимке, перечитанном по событию `pane.agent_status_changed`: при `idle` плагин MUST один раз сообщить, что агент готов. Если панель исчезла раньше, плагин MUST сообщить, что панель закрыта. Сроки, таймеры и опрос MUST NOT использоваться.

#### Scenario: Агент запускается
- **WHEN** `agent.start` ответил успехом, а состояние агента панели ещё не `idle` и не `blocked`
- **THEN** в запросе `agent.start` нет `timeout_ms`, плагин сообщает, что агент запускается, Neovim остаётся отзывчивым, сообщения о готовности нет

#### Scenario: Агент готов
- **WHEN** после ответа `agent.start` состояние агента панели становится `idle`
- **THEN** плагин один раз сообщает, что агент готов; дальнейшие смены состояния этой панели новых сообщений о запуске не дают

#### Scenario: Панель закрыта до готовности
- **WHEN** после ответа `agent.start` панель исчезает из снимка раньше, чем состояние агента становится `idle`
- **THEN** плагин сообщает, что панель закрыта, и больше за ней не следит

### Requirement: Ошибки запуска
Если `tab.create`, `pane.split` или `agent.start` завершаются ошибкой, плагин MUST показать код и текст ошибки сервера. Созданные к этому моменту вкладка или панель MUST оставаться как есть: плагин их не закрывает.

#### Scenario: Агент не запустился
- **WHEN** `tab.create` выполнен, а `agent.start` возвращает ошибку
- **THEN** пользователь видит ошибку, созданная вкладка остаётся открытой

### Requirement: Агент не готов
Если после запуска состояние агента созданной панели становится `blocked` (открыт диалог доверия к каталогу), плагин MUST сообщить, что агент не готов и ждёт ответа на диалог, и подсказать ответ: подключение с вводом (`:Claudr attach`) или клавиши (`:Claudr keys`), а когда состояние станет `idle`, MUST сообщить, что агент готов. Панель MUST оставаться; плагин MUST NOT запускать агента повторно. Ошибка `agent.start`, включая `agent_not_ready`, — по требованию «Ошибки запуска».

#### Scenario: Каталог без доверия
- **WHEN** после ответа `agent.start` состояние агента панели становится `blocked`
- **THEN** плагин сообщает, что агент не готов и ждёт ответа на диалог доверия, и называет `:Claudr attach` и `:Claudr keys`; панель остаётся, повторного `agent.start` нет

#### Scenario: Ответ на диалог
- **WHEN** пользователь отвечает на диалог доверия подключением с вводом или клавишами
- **THEN** состояние агента становится `idle`, плагин сообщает, что агент готов, узел панели показывает `idle` по событию `pane.agent_status_changed`; повторного `agent.start` нет

#### Scenario: Сервер ответил agent_not_ready
- **WHEN** `agent.start` отвечает ошибкой `agent_not_ready`
- **THEN** плагин показывает код и текст ошибки, панель остаётся, повторного `agent.start` нет

### Requirement: Идентификатор сессии нового агента
Идентификатор сессии Claude Code MUST браться из `agent_session.value` записи агента: из ответа `agent.start`, если поле в нём есть, иначе из снимка после запуска. Файл транскрипта появляется только после первого сообщения в сессии: его отсутствие у только что запущенной сессии MUST NOT считаться ошибкой.

#### Scenario: Сессия без сообщений
- **WHEN** агент запущен, и ни одного сообщения ему не отправлено
- **THEN** узел панели связан с сессией по `agent_session.value`, транскрипта ещё нет, ошибки нет

#### Scenario: Первое сообщение
- **WHEN** агенту отправлено первое сообщение
- **THEN** появляется транскрипт с именем `<идентификатор сессии>.jsonl`, субагенты и фоновые команды сессии начинают читаться

### Requirement: Новая сессия в дереве
Запущенная сессия MUST появляться в дереве по событиям herdr (`pane_created`, `pane_agent_detected`), без специальной обработки результата запуска: строкой новой вкладки или состоянием строки вкладки, в которой разделена панель.

#### Scenario: Появление узла
- **WHEN** после `tab.create` и `agent.start` приходят `pane_created` и `pane_agent_detected`
- **THEN** дерево содержит строку новой вкладки с состоянием агента, строки панели с агентом нет

### Requirement: Сервер недоступен
Если сервера нет, запуск MUST завершаться сообщением о недоступности сервера.

#### Scenario: Запуск без сервера
- **WHEN** пользователь запускает сессию, а сервера herdr нет
- **THEN** плагин сообщает о недоступности сервера и ничего не создаёт
